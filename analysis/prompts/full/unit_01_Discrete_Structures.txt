FORMULAS AND FACTS
- Conditional equivalences: p->q = ~p v q = ~q->~p; ~(p->q) = p ^ ~q (Converse and inverse are NOT equivalent to p->q.)
- Biconditional: p<->q = (p->q)^(q->p) = (p^q) v (~p^~q); ~(p<->q) = ~p<->q (Negation moves to one side only.)
- De Morgan / quantifier negation: ~(p^q)=~p v ~q; ~exists x P = forall x ~P; ~forall x P = exists x ~P (Quantifier flips when negating.)
- Implication distribution: (p->r)^(q->r) = (p v q)->r ; (p^q)->r = (p->r) v (q->r) ((p^q)->r is not equal to (p->r)^(q->r).)
- Quantifier non-equivalences: forall x(P v Q) != forall x P v forall x Q ; exists x(P^Q) != exists x P ^ exists x Q (Forall distributes over AND, exists over OR only.)
- Reflexive relations count: 2^(n^2-n) on n elements (4 elements: 2^12) (Symmetric relations: 2^(n(n+1)/2).)
- Inclusion-exclusion: |AuBuC| = |A|+|B|+|C|-|AnB|-|AnC|-|BnC|+|AnBnC| ('Neither' = total - union.)
- Pigeonhole: min objects to guarantee r in one box with k boxes: k(r-1)+1 (For cards use the worst case of all other suits.)
- Stars and bars: non-negative solutions of x1+..+xk=n : C(n+k-1,k-1) (Subtract lower bounds first.)
- Onto functions: onto(n->k) = sum_i (-1)^i C(k,i)(k-i)^n (5 to 4 = 240; 7 to 3 = 1806.)
- Multinomial coefficient: coefficient of x^a y^b z^c in (x+y+z)^n = n!/(a!b!c!) (7!/(2!3!2!) = C(7,2)C(5,3).)
- Linear recurrence solution: repeated root r: a_n=(A+Bn)r^n; f(n)=a f(n/2)+c solved with n=2^K (Stairs: Fibonacci f(1)=1, f(2)=2.)
- Catalan numbers: binary trees / BSTs with n nodes = (2n)!/((n+1)!n!) (Labelled binary trees multiply by n!.)
- Handshake lemma: sum of degrees = 2|E|; number of odd-degree vertices is even (Used to find unknown vertex count.)
- Tree and forest edges: tree: E=V-1; forest with k components: E=V-k (Min edges with k components = n-k.)
- Euler's planar formula: V-E+F=2 (connected planar); E<=3V-6 (6 vertices of degree 4: E=12, F=8.)
- Cayley spanning trees: tau(K_n)=n^(n-2); tau(C_n)=n (K2,2=C4 has 4.)
- Hamiltonian conditions: Dirac: deg(v)>=n/2; Ore: deg(u)+deg(v)>=n for non-adjacent u,v; K(m,n) Hamiltonian iff m=n>=2 (Conditions are sufficient, not necessary.)
- Colouring facts: bipartite iff 2-colourable iff no odd cycle; planar => 4-colourable; chi<=Delta+1 (Bipartite has no ODD cycles.)
- Edge counts of graph families: K_n: n(n-1)/2; C_n: n; W_n (n vertices): 2(n-1); K_{n,n}: n^2; Q_n: n*2^(n-1) (W4 = K4 is the regular wheel.)
- Boolean algebra counts: Boolean functions of n variables: 2^(2^n); finite Boolean algebra has 2^n elements (No Boolean algebra with 5 elements.)
- Poset under divisibility: GLB = gcd, LUB = lcm (Greatest element requires everything dividing it.)
- Dual of Boolean expression: swap + and ., swap 0 and 1; absorption a+ab=a (Do not complement literals.)
- Poisson: P(X=0)=e^(-lambda t); P(X=k)=e^(-lt)(lt)^k/k! (Convert the rate to the same time unit.)
- Conditional and union probability: P(A|B)=P(AnB)/P(B); P(AuB)=P(A)+P(B)-P(AnB); independent: 1-(1-a)(1-b) (Divisible by 2 or 5: 1/2+1/5-1/10=3/5.)
- Total 5-card hands: C(52,5)=2,598,960 (Atomic events in the joint distribution.)
- Euler phi and theorems: phi(n)=n prod(1-1/p); a^phi(n)=1 mod n (gcd=1); a^(p-1)=1 mod p; phi(45)=24 (a^p = a mod p, not 1.)
- Group facts: order of a divides |G|; even order => element of order 2; (xy)^-1=y^-1x^-1; Aut(Z,+) has 2 elements; x^2=e for all x => abelian (x^3=1 for all x does not force commutativity.)
- LP duality rules: max primal <= constraints => dual min >= with y>=0; equality constraint => unrestricted dual variable; BFS in transportation has m+n-1 allocations (Dual objective uses primal RHS.)
- Place-value/base: (d_k...d_0)_b = sum d_i b^i ; digits < b ; roots 4 and 7 of x^2-10x+26 means 4+7=11=10 in base b, so b=11 (Check that digits fit the base.)

QUESTION FAMILIES (most repeated first; each is a question type the exam keeps reusing)
- Check reflexive/symmetric/antisymmetric/transitive properties of a given relation (7x): Test reflexive (all (a,a) present), symmetric (every (a,b) has (b,a)), antisymmetric (no a!=b both ways), transitive (check chains). Eliminate options with one failing property. For infinite relations find a counterexample.
- Full joint distribution table: marginal/conditional/union (6x): Add matching cells for marginals; P(A|B)=P(A and B)/P(B); P(A or B)=P(A)+P(B)-P(A and B).
- Truth value of quantified statements over integers/reals (5x): For each statement find a witness (for exists) or a counterexample (for forall) in the given universe. Quick tests: n=0, n=1, n=-1, n^2 vs n for 0<n<1 (not integers), and remember n+m=4 with n-m=1 needs n=2.5 (no integer solution).
- Which pairs are (not) logically equivalent / identify valid equivalence statements (5x): Use contrapositive, De Morgan, distribution of implication: (p->r)^(q->r) = (p v q)->r while (p^q)->r = (p->r) v (q->r). Test suspicious options with a 2-3 row truth table.
- Group theory statement-check (5x): Facts: identity and inverse unique; element order divides |G|; even-order group has element of order 2; (xy)^2=x^2y^2 for all x,y implies abelian but x^3=1 does not; finite closed subset is a subgroup; group has at least one element.
- Euler/Fermat/modular computation (5x): phi(n)=n*prod(1-1/p); a^phi(n) = 1 mod n; Fermat a^(p-1)=1 mod p (not a^p=1); repeated squaring.
- Evaluate the passage LP at corner points (optimum value/solution) (4x): Compute intersection points of constraints, evaluate objective at feasible vertices, choose max/min.
- Graphical LP solution (4x): Plot constraints, list feasible vertices and evaluate objective. For feasibility questions substitute each point into all constraints.
- Match propositional equivalences (implication, biconditional, negation, De Morgan) (3x): Convert everything to the standard forms: p->q = ~p v q, p<->q = (p^q) v (~p^~q), ~(p->q)= p^~q, ~(p v q)=~p^~q, ~(p<->q)= ~p<->q. Match by elimination using one or two unambiguous pairs.
- Translate English sentences to propositional logic (3x): Map: 'neither P nor Q' = ~P ^ ~Q; 'if P then Q' = P->Q; 'necessary for P is Q' = P->Q (P implies Q); 'sufficient' = antecedent; 'only if' = consequent.
- Quantifier translation (English <-> predicate logic) (3x): 'Some A are not B' = exists x (A ^ ~B); 'all A are B' = forall x (A -> B); 'X is loved by everyone' = forall x L(x,X). For forall x exists y (x<y): for every x there is a larger y.
- Identify/prove an equivalence relation (3x): Check reflexive, symmetric, transitive. Equal-mod-k or 'same value of a function' type relations are equivalences; 'f(0)=g(0) or f(1)=g(1)' fails transitivity.
- Inclusion-exclusion counting with 2 or 3 sets (3x): |AuB|=|A|+|B|-|AnB|; |AuBuC|=sum singles - sum pairs + triple. Neither = total - union.
- Pigeonhole principle (minimum number to guarantee) (3x): Worst case: fill every box to r-1, then add one: N = k(r-1)+1. For 'at least three hearts' count all non-hearts (39) + 2 hearts, plus 1 = 42.
- Recurrence relations: set up and solve (3x): Linear homogeneous: characteristic equation; repeated root r gives (a+bn)r^n (r^2-8r+16 => 4^n and n4^n). Divide and conquer f(n)=a f(n/2)+c: unroll with n=2^K. Stairs: f(n)=f(n-1)+f(n-2), Fibonacci.
- Trees and forests: vertex/edge counts (3x): Tree: E=V-1. Forest with k components: E=V-k, so minimum edges of a graph with k components is n-k. Use sum of degrees = 2E to find unknown n.
- Elementary probability with balls/coins (3x): Favourable/total with combinations: C(6,2)C(4,2)/C(10,4)=3/7.
- Converse, inverse, contrapositive, implication terminology match (2x): p->q: converse q->p, inverse ~p->~q, contrapositive ~q->~p (equivalent to original). Equivalence is p<->q.
- Identify tautologies among given formulas (2x): Assume the formula is false and try to force a contradiction (false conclusion, true premise); or check the single falsifying assignment for each.
- Negation of quantified statements (2x): ~exists x Q = forall x ~Q; ~forall x Q = exists x ~Q. 'Some students like hockey' negates to 'every student dislikes hockey'.
- Empty-set and nested-set membership/subset (2x): Distinguish phi (no elements) from {phi} (one element). x in S needs x listed as an element; x subset S needs all elements of x in S.
- Set algebra identity / operation matching (2x): A-B = A n B^c; symmetric difference = (A-B)u(B-A); A-(BuC)=(A-B)n(A-C); A-(BnC)=(A-B)u(A-C); A n (B-C)=(AnB)-(AnC). Verify with a Venn or small example.
- Poset GLB/LUB and greatest/least element under divisibility (2x): In (Z+, |): GLB = gcd, LUB = lcm of the set. Greatest element exists only if one element is divisible by all others (and least if one divides all).
- Boolean algebra statement-check (atoms, complement, direct product, NAND/NOR) (2x): A finite Boolean algebra has 2^n elements (no 5-element one); complements are unique; direct product of Boolean algebras is a Boolean algebra; any network can be built from NAND or NOR alone; two Boolean algebras with the same number of atoms are isomorphic.
- Boolean laws and dual expressions matching (2x): Dual: swap + with ., 0 with 1 (leave literals). Laws: absorption a+ab=a, bound a+1=1, identity a+0=a, distributive.
- Stars and bars: integral solutions / balls into bins (2x): Non-negative solutions of x1+..+xk = n: C(n+k-1, k-1). With lower bounds subtract them from n first (29-1-2-3=23, C(26,3)=2600).
- Onto functions / distributing distinct objects with every box non-empty (2x): Onto count = sum_{i=0}^{k} (-1)^i C(k,i)(k-i)^n (= k! S(n,k)). 5 jobs on 4 people = 240; 7 people on 3 floors = 3^7-3*2^7+3 = 1806.
- Inclusion-exclusion in counting (bit strings, integers up to N) (2x): |A u B| = |A|+|B|-|A n B|. Bit strings starting with 1 (2^9), ending 00 (2^8), both (2^7): 640. Odd or perfect square up to 100: 50 odd + 5 even squares (4,16,36,64,100) = 55.
- Multiplication rule counting (labels, ordered selections) (2x): Product rule; ordered selection without replacement is nPr: 42*41*40 = 68880. Labels: 26 letters x 99 positive two-digit numbers = 2574.
- Handshaking lemma (2x): Sum of degrees = 2|E|; number of odd-degree vertices is even.
- Planarity of drawn graphs (2x): Look for a K5 or K3,3 subdivision (Kuratowski); otherwise redraw without crossings. Check E<=3V-6 as a quick necessary test.
- Graph colouring and bipartite equivalence (2x): Bipartite = 2-colourable = no odd cycles; trees are 2-colourable; max degree d needs at most d+1 colours; planar graphs are 4-colourable.
- Hamiltonian sufficient conditions (Dirac/Ore) (2x): Dirac: n>=3 and deg(v)>=n/2 for all v => Hamiltonian. Ore: deg(v)+deg(w)>=n for each non-adjacent pair. Ore's condition is the sum, not the n/3 trap.
- Number of spanning trees of small graphs (2x): Cayley: K_n has n^(n-2); cycle C_n has n; K2,2=C4 has 4; otherwise Kirchhoff or deletion-contraction (tau(G)=tau(G-e)+tau(G/e)).
- Standard graph family properties (edges, regularity) (2x): K_n: n(n-1)/2 edges; C_n: n; W_n (n vertices): 2(n-1), regular only for W4=K4; K_{n,n}: n^2; Q_n: n*2^(n-1).
- Formulate the LP from the passage: objective (2x): Objective coefficient = cost/profit per unit of each product times variable (12x+20y for diet; 30x+50y for cloth).
- Formulate the LP from the passage: constraints (2x): One constraint per resource/nutrient; coefficient matrix columns are products. Diet = '>=' constraints, production = '<=' constraints.
- Write the dual of the passage LP (2x): Primal min with >= constraints => dual max with <= constraints, RHS of dual = primal costs, dual objective uses primal RHS, A is transposed.
- Simplex / dual simplex iterations (2x): Entering variable: largest positive Cj-Zj (max). Leaving: min ratio. Dual simplex: leaving row = most negative RHS.
- LP duality theorems and rules (2x): Equality constraint in max primal => unrestricted dual variable; weak/strong duality; optimal tableau gives dual solution.
- Semigroup property reasoning (2x): Use the given hypothesis to force identities; two-element semigroup with a*a=b: b*b=b.
- Homomorphism and automorphism of integer/real groups (2x): Kernel decides injectivity; image decides surjectivity; Aut(Z,+)={x->x, x->-x}.
- Unknown-base arithmetic equation (2x): Expand each number in its base as polynomial in b, set equal, solve and check digit validity.
- Radix and valid digit questions (2x): Digits must be smaller than base; for a quadratic with roots in base b, use sum/product of roots.
- Poisson probability of zero arrivals (2x): P(0)=e^(-lambda t); convert rate to the time window (30/hr for 40 min => 20).
- Probability of numbers divisible by 2 or 5 (2x): Inclusion-exclusion: 1/2+1/5-1/10 = 3/5.
