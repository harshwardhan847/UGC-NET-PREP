FORMULAS AND FACTS
- Frame buffer size: bytes = X * Y * bits_per_pixel / 8 (640*480*12/8 = 460800 B = 450 KB) (Divide by 8 for bytes, then 1024 for KB; 1 MP is ~1e6 pixels and 1-bit images need 1/8 byte.)
- Colour lookup table size: LUT = 2^bits_per_pixel entries * (3*8 bits) = 2^bits * 3 bytes (Frame buffer 10 bpp: LUT 1024 entries * 3 bytes = 2^10 + 2^11 bytes.)
- Refresh rate: rate = 1 / (pixels * access time) (640*480*200 ns = 61.4 ms, about 16 fps) (Pixels count first; 1 bit depth does not change per-pixel time.)
- Aspect-ratio resize: h2 = h1 * w2 / w1 (768*640/1024 = 480) (Keep ratio, scale both sides by the same factor.)
- 2D scaling: x' = sx*x, y' = sy*y; matrix diag(sx, sy) (Factor > 1 enlarges, < 1 shrinks; applied about origin.)
- Scaling about fixed point F: P' = F + s(P - F) (F stays unchanged; compute each vertex difference from F.)
- Homogeneous 2D matrices: Translate [[1,0,tx],[0,1,ty],[0,0,1]]; Scale diag(sx,sy,1); Shear-x [[1,h,0],[0,1,0],[0,0,1]]; Rotate [[c,-s,0],[s,c,0],[0,0,1]] (Composite M = M_last ... M_first; the rightmost matrix acts first.)
- Reflection about X axis: diag(1,-1); determinant -1, so not a rotation (Reflection is not a rotation matrix; y-axis reflection is diag(-1,1).)
- Perspective division: x' = x/z, y' = y/z via homogeneous w; non-linear in Cartesian, linear only in homogeneous coordinates (Parallel lines converge except those parallel to the view plane; parallel projection = viewer at infinity.)
- Orthographic projection: Affine: preserves parallel lines, no size change with depth (Cavalier: no foreshortening; cabinet: half-scale depth; both oblique.)
- Cubic Bezier: P(t)=sum B_i P_i, with P(0)=P0, P(1)=P3, P(1/2)=(P0+3P1+3P2+P3)/8; 4 control points, inside convex hull (Interpolates only end points; tangent at ends along P1-P0 and P3-P2.)
- Phong specular term: I_s = k_s (R . V)^n (reflected vector and view vector) (Not the normal and light vector; that is the diffuse term.)
- Clipping facts: Cohen-Sutherland: accept if both outcodes 0000, reject if AND != 0; Sutherland-Hodgman clips polygons against convex window; a triangle clipped by a rectangle gives at most 7 sides (Sutherland-Hodgman is polygon clipping, not line clipping.)
- Row-major 3D address: addr(A[r][s][t]) = base + w*(b*c*r + c*s + t) for int A[a][b][c] (First index multiplies b*c; the leading dimension a never appears.)
- Array/pointer identity: a[i] = *(a+i); a[i][j][k] = *(*(*(a+i)+j)+k); ptr[-1] legal; &arr+1 moves past whole array (Pointer arithmetic scales by element size.)
- Pointer operation legality: ptr +/- int -> ptr; ptr - ptr -> int; ptr + ptr, ptr*int, ptr/int illegal; int to pointer needs a cast (Option "pointer - pointer -> pointer" is the usual trap.)
- Struct alignment: member offset multiple of its size; struct size multiple of largest member alignment; union size = largest member (Add padding after members as well as before.)
- Little-endian value: two-byte value = byte1*256 + byte0 (5, 2 gives 517) (LSB stored at lowest address.)
- C operator precedence: arithmetic > shift > relational (<,>,>=) > equality (==) > && > || > ?: > assignment (=,+=) > comma (Relational binds tighter than equality.)
- Macro expansion: SQR(x) = (x*x) with x = b+2 expands to b+2*b+2 = 11 for b=3 (No parentheses means textual substitution.)
- Number literals: 0x10 = 16, leading 0 means octal: 010 = 8 (Sum 24, not 26.)
- Bit loop: while(n){c+=n&1; n>>=1;} counts set bits; N&(N-1)==0 tests power of 2 (Check the return statement for assignment typos.)
- Loop iteration count: while(p<b){p*=a;x++;} gives x = ceil(log_a b) (Ceil not floor because exit needs p >= b.)
- Geometric series sum: S = a/(1-r), |r|<1 (recursive Java f sums to 0.2) (Check the base case before summing.)
- Constructor/destructor order: Constructors run base -> derived; destructors derived -> base; virtual destructor needed for delete through base pointer (Without virtual, only the base destructor runs.)
- Parameter passing: By value: copy, caller unchanged; by reference / pointer: original changed; swapping char* needs char** (f1(char*,char*) swap has no caller effect.)
- XML validity: valid XML => also well-formed (not the reverse); XML is case sensitive; namespaces provide globally unique names (Valid means conforms to DTD/schema.)
- Visibility: Back-face culling: object space; Painter and z-buffer: image/depth-order; collinear with viewpoint means nearer obscures farther (Z-buffer depth is typically 16/32 bits.)

QUESTION FAMILIES (most repeated first; each is a question type the exam keeps reusing)
- HTML tags and attributes (6x): script encloses JS; map defines clickable image regions; alt text aids accessibility; valign/align for cells; list types.
- Loop tracing with small counters (5x): Write variable table per iteration; watch break, step sizes and the loop test; Euclid-by-subtraction ends at gcd.
- Polymorphism, virtual functions and inheritance benefits (5x): Run-time polymorphism = virtual functions + base-class interface; pure virtual (=0) makes a class abstract; overriding is late binding, overloading is early binding.
- Call by value vs reference tracing (5x): Value copies: swap on copies does nothing; reference/pointer swaps change originals; swapping char* locally vs via char** differ.
- XML properties, validity and namespaces (5x): XML is case sensitive, user-defined tags, describes data not presentation; well-formed = syntax correct, valid = conforms to DTD/schema; namespaces give unique names.
- Frame buffer, LUT and image-size arithmetic (5x): Bytes = X*Y*bpp/8; LUT = 2^bits entries * 3 bytes; refresh = 1/(pixels*access time); resize keeps aspect ratio.
- Homogeneous 3x3 transformation matrices (5x): Read the matrix: translation in last column, scale on diagonal, shear off-diagonal; compose right-to-left; reflection about x-axis is diag(1,-1).
- Projection properties (perspective, parallel, oblique) (5x): Perspective: farther is smaller, parallel lines converge, divide by z, needs homogeneous coords; orthographic is affine and keeps parallels; cavalier no foreshortening, cabinet half.
- Clipping algorithms identification (5x): Line clipping: Cohen-Sutherland, Liang-Barsky, Nicholl-Lee-Nicholl; polygon clipping: Sutherland-Hodgman (convex window); clipping removes outside parts.
- Pointer arithmetic and indexing output (4x): Rewrite everything as *(base+offset); p++ post-increments after use; &arr+1 jumps the whole array; ptr[i]=*(ptr+i) and negative indices are legal.
- Legal and illegal pointer operations (4x): Allowed: ptr+-int, ptr-ptr (gives int), assigning &var. Illegal: ptr+ptr, ptr*int, ptr/int, assigning int to pointer without cast, &constant.
- One-line expression gotchas (ternary, comma, macro, literals) (4x): Evaluate exactly as the compiler: ternary picks branch, comma yields last value, macro expands textually (b+2*b+2), 0x is hex and leading 0 is octal.
- Constructor facts in C++ (4x): Constructors: auto-invoked, no return type, can be overloaded, not inherited, need not be friend, defined outside as Class::Class(...) without explicit.
- Access control: protected inheritance, friend, scope resolution (4x): Protected inheritance makes public/protected base members protected in derived; objects outside cannot access them; friend breaks encapsulation without being a member.
- Language-concept true/false statements (4x): Recall: static binding at compile time, globals reduce function independence, C is weak-static, Java strong-static, logical vs syntax errors.
- Display and colour terminology (4x): Raster scan = lines of dots; fluorescence is light during beam, phosphorescence after; hue is wavelength; input/output classification.
- 2D scaling arithmetic (4x): x'=sx*x, y'=sy*y; scaling about a fixed point F: P'=F+s(P-F).
- Hidden-surface and visibility (4x): Painter sorts by depth, z-buffer is image-space, back-face culling is object-space; collinear with viewpoint means nearer point obscures.
- Line-drawing algorithm facts (4x): DDA and Bresenham/midpoint draw lines; Bresenham is integer-only, no rounding; scan conversion causes staircase, unequal brightness, picket fence.
- Bezier and curve facts (4x): Cubic Bezier has 4 control points, passes through first and last only, stays in convex hull, tangent at ends; B-splines give local control.
- Bit-loop functions (popcount / power-of-2 / bit reversal) (3x): Trace n&1 and n>>=1 on a small number; popcount counts 1-bits; a stray "counter = 1" in the return makes the answer a constant test. For reversal, build b = 2b + (a&1).
- Struct/union memory layout, padding and endianness (3x): Align each member to a multiple of its size, pad struct to multiple of max alignment, union size = largest member; little endian value = b1*256+b0.
- Ordering process steps (3x): Know the canonical sequence: do-while is init -> body -> test; viewing pipeline is world scene -> viewing coords -> normalized -> device; runtime is statement -> compile -> type -> allocate -> deallocate.
- Java facts and execution model (3x): final class cannot be extended; Java single-inheritance of classes; JVM needs class loader + interpreter; JDK/JRE/JNDI/RMI meanings.
- Java output tracing (references, equals, recursion) (3x): Arrays are references so aliases share changes; equals(Good) overloads rather than overrides Object.equals; unroll recursion left-to-right.
- Recursive Java f(m,n) geometric series (2x): Unroll the recursion: result = m/n added to the recursive term; terms form a geometric series a/(1-r); plug values.
- Recursion call-counting in C (2x): Write the argument chain per call (81->27->9->3 for fun; a halving chain per outer b for Cal) and count calls/prints.
- Pointer concept statements (what pointers can/cannot do) (2x): Pointers store addresses, can point to pointers, access arrays, simulate call by reference, build dynamic structures; they are not auto-dereferenced.
- Multi-dimensional array to pointer expression (2x): a[i][j][k] = *(*(*(a+i)+j)+k); count dereference levels equal to dimensions.
- Decoding C declarations (function pointer / typedef) (2x): Read declarations inside-out: int (*f)(int,int) is a pointer to function; typedef (*(*arrfptr[3])())[10] is array of 3 pointers to functions returning pointer to array of 10.
- Operator precedence ordering (2x): Order: shift > relational (<,>,>=) > equality (==) > && > || > ?: > assignment (+=); arithmetic binds tightest here.
- C file-handling functions and steps (2x): fopen -> check error -> read/write -> fclose; fseek sets position, ftell gives position, rewind goes to start, feof tests end.
- JavaScript semantics (2x): Variables have no type, values do; global this.y vs closure local y.
- Markup and web-term identification (2x): HTML, XML, DHTML are markup languages; HTML structure, DHTML dynamic, XML data.
- Shading models (2x): Phong specular uses (R.V)^n; Phong shading interpolates normals, Gouraud interpolates colour and is cheaper.
