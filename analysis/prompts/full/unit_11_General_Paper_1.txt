FORMULAS AND FACTS
- Percent change: (New - Old)/Old x 100 (Base is the "than" quantity)
- A is x% more than B: (A - B)/B x 100 (Dividing by A is the typical wrong option)
- Average: Sum of values / number of values (Convert ratio to actual numbers first)
- Share from ratio: Share = ratio part/sum of parts x total; fractions first multiplied by LCM (1/2:1/3:3/4 = 6:4:9) (Convert fractional ratio to integers)
- Work rates: Sum of 1/time = 1/total time (Unknown helpers contribute n/their days)
- Man-hours: M1 D1 H1 / W1 = M2 D2 H2 / W2 (Same work so equate products)
- Speed-time-distance: Time = distance/speed; sum of segment times = total time (Quadratic; test the options)
- Discount: SP = MP x (100 - d)/100 (Find MP first)
- Mixture cost and gain: SP = (total cost/total quantity) x (100 + gain%)/100 (Weighted-average cost)
- Direction distance: Net displacement = sqrt(dx^2 + dy^2) (Resolve opposite moves before Pythagoras)
- Base conversion: (abc)_n = a n^2 + b n + c (Convert each to decimal then order)
- Mirror coding: A=Z, B=Y ...: letter + mirror letter = 27 (Reverse alphabet mapping)
- Alternating shift coding: +2, -2, +2 ... on successive letters (Check position pattern)
- Number series: Differences, ratios, second differences (Doubling multipliers x3,x6,x12,x24)
- Square of opposition: A-O and E-I contradictory; A-E contrary (both false allowed); I-O subcontrary (If A false then O true)
- Denotation vs connotation: Greater connotation implies lesser denotation (Species have more connotation)
- Syllogism AII-2: Middle term predicate in both premises gives undistributed middle fallacy (Figure 2 needs a negative premise)
- OSI layers: Physical, Data link, Network, Transport, Session, Presentation, Application (Sequence questions give bottom-up or top-down)
- Memory taxonomy: LTM = explicit (episodic, semantic) + implicit (procedural, priming) (Semantic = general world knowledge)
- Bandura observational learning: Attention, retention, reproduction (production), motivation (Identification is not an element)
- Mercalli vs Richter: Mercalli = intensity/damage; Richter = magnitude/energy (Common trap)
- Education timeline: Wood 1854, Curzon 1904, Sadler 1917, UEC 1948, SEC 1952, UGC 1956, Kothari 1964 (Chronology questions)
