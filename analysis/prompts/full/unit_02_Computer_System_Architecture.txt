- Questions are overwhelmingly factual recall, ordered-sequence and match-the-list formats; roughly 70% need no calculation, so breadth beats depth.
- Ordering questions (instruction cycle, ISR steps, memory hierarchy, DMA steps, arithmetic pipeline) recur with the options shuffled; the instruction cycle order alone appeared in 5 papers and the ISR sequence twice.
- Exact repeats are common across shifts/papers: Dec 2022 Shift I/II primary-vs-secondary statements, and ISR sequence in Dec 2024 and June 2024 Cancelled.
- Calculation questions reuse the same formula with new numbers: pipeline (k+n-1) formula (4 papers), Amdahl (3 papers), direct-mapped fields (2), average access time (2), instruction-field bit widths (2), microinstruction size (2).
- Statement-combination and 'which are NOT' options punish half-knowledge; distractors are swapped definitions (write-through vs write-back, isolated vs memory-mapped).
- Digital logic is tested through K-map and Boolean simplification at medium difficulty; every paper has about one such question and the answer is checkable by plugging minterms.
- Cross-unit overlap: Boolean/K-map and gates feed Unit 2 only here but number systems and 8085/basic-computer content appear in OS/programming style questions elsewhere; digital-logic tags are sometimes assigned to memory-sizing questions.
- Never asked so far: cache replacement (LRU/FIFO) numericals, hazard types/forwarding, CPI/MIPS computation, Booth multiplication, hit-ratio with miss-penalty tables, virtual memory addressing. Pipeline hazards are a likely future gap.
- Difficulty is mostly 1-2 on a 3-point scale; the only multi-step items are IEEE-754 conversion, 2-level cache time, program traces and the DRAM refresh calculation.
- Recent papers (2023-2025) lean toward ordered-list and statement formats in CPU, I/O and memory hierarchy, with fewer pure numericals.

FORMULAS AND FACTS
- Instruction word bit allocation: word bits = mode/indirect + opcode + register code + address; address bits = log2(#words); register bits = log2(#registers) (Opcode = remainder after other fields; 512K words -> 19 address bits, 256K -> 18.)
- Mano basic-computer instruction types: I + 3-bit opcode + 12-bit address; opcode 000-110 memory ref; I=0 & 111 register ref; I=1 & 111 I/O ref (Register ref: CLA, CMA, INC, SZA, SNA, SPA; I/O: INP, OUT, SKI, SKO; ISZ is memory-reference.)
- Instruction cycle: Fetch -> Decode -> Calculate EA -> Fetch operand -> Execute; fetch: PC->MAR->Memory->MBR->IR (EA/operand fetch come after decode.)
- Effective address by mode: immediate: operand=field; direct: EA=A; indirect: EA=M[A]; register: EA=R; reg indirect: EA=[R]; indexed: EA=A+XR; relative: EA=PC+A (Indirect needs 2 memory refs for operand; register needs 0.)
- Memory capacity: bits = 2^(address lines) x data lines; address lines = log2(words); chips = total / chip size (Word-addressable: divide bytes by word size first.)
- Direct-mapped cache fields: address = tag | line | offset; offset = log2(block), line = log2(#lines); main memory = 2^(tag+line) words (Cache size = 2^line index (x block size for total).)
- Average access time: T = h*Tc + (1-h)*Tm (recursive for multi-level) (Check whether the question gives Tm inclusive of cache probe.)
- Memory hierarchy speed order: Registers > Cache(SRAM) > DRAM > SSD > HDD > Optical > Tape (Watch ascending vs descending.)
- Write policies: write-through: cache+memory updated; write-back: cache only, dirty bit marks modified block (Trap: statements swapped.)
- DRAM refresh overhead: fraction = (rows x refresh time per row) / refresh interval (256Mb as 16K x 16K: 16K rows x 100ns / 50ms = 3.3%.)
- K-map rules: group 1s in powers of 2, wrap edges, don't care used only if it enlarges a group; each group = product of constant variables (Shortcut: test each option against the minterm list.)
- Boolean identities: x+xy=x, x+x=x, x+1=1, x+0=x, x+x'y=x+y, A'B+AB'+AB=A+B, A xor 1 = A', A xor A = 0 (Names: idempotent, identity, domination, absorption.)
- De Morgan: (A+B)' = A'B', (AB)' = A'+B'; complement of SOP = product of complemented sums (Complement every literal and swap AND/OR.)
- Gate outputs for inputs 00: NAND=1, NOR=1, XOR=0, XNOR=1; XOR is odd function (Universal gates: NAND, NOR.)
- Decoder/mux/encoder sizes: decoder n -> 2^n; encoder 2^n -> n; mux 2^n -> 1; demux 1 -> 2^n; k arbiters need priority encoder of k lines (ceil(log2 k) outputs) and decoder back (Priority encoder resolves simultaneous inputs; 5 arbiters -> 8x3 and 3x8.)
- Common bus: n registers of m bits -> m multiplexers each n x 1 (8 registers 16 bits -> 16 MUX of 8x1.)
- Cascaded counters: states = product of moduli (MOD-2 followed by MOD-5 = 10); N-bit ring counter has N states (Ripple counter = output of one FF clocks next.)
- SR flip-flop: S=R=0 hold; S=1,R=0 set; S=0,R=1 reset; S=R=1 invalid (JK: J=K=1 toggle.)
- ISR / programmed I/O orders: ISR: save regs, check flag, service, restore regs, enable interrupts; programmed input: read status, check flag, read data, store to memory; DMA: request, grant, transfer, release (Interrupt enable is turned on near the end.)
- Isolated vs memory-mapped I/O: isolated: separate address spaces + IN/OUT; memory-mapped: shared address space, ordinary load/store (Memory-mapped uses same control signals as memory.)
- Two's complement: -N = 2^n - N = invert + 1; range -2^(n-1) to 2^(n-1)-1; overflow iff operands same sign and result sign differs (8-bit: -128..127; unsigned 0..255. Subtraction = add 2's complement.)
- Base conversion: hex digit = 4 bits, octal digit = 3 bits; fraction: multiply by 2 (Regroup binary from the radix point outward.)
- Gray code: g_i = b_i xor b_(i+1); MSB unchanged; adjacent codes differ in 1 bit (Decimal 8 = 1000 -> 1100.)
- Self-complementing codes: 2421 and excess-3 (and excess-3 Gray per key) are self-complementing; 8421 is not (8421 BCD is not self-complementing.)
- IEEE-754 single precision: 1 sign | 8 exponent (bias 127) | 23 mantissa; value = (-1)^s x 1.m x 2^(e-127) (-40.1 = 0xC2206666.)
- Arithmetic shift: ASR keeps sign bit and divides by 2; ASL multiplies by 2 (Logical shift does not preserve sign.)
- Amdahl's law: Speedup = 1 / ((1-f) + f/s); with p processors: T = T_serial + T_parallel/p (0.3 fraction at 2x -> 1.18; 200+800/16 = 250.)
- Vector processor cycles: cycles = (elements / lanes) as keyed; x per-op cycles only if specified as a pipeline (The key gives 64 = 1024/16, ignoring the 5-cycle latency.)
- Pipeline time and speedup: T_pipe = (k+n-1) x t_clock; S = n*t_np / ((k+n-1)*t_clock); max speedup -> k (t_clock = max stage delay + latch delay; speedup never equals k exactly.)
- Pipeline speedup with different CPI: speedup = (avg unpipelined time) / (clock + overhead) (Unpipelined avg CPI 4.4 x 10 ns = 44 ns; pipelined 11 ns -> 4x.)
- Microinstruction size: sum of ceil(log2(options)) over fields + address bits (log2 control memory) (15 ops -> 4 bits; 4 status bits -> 2 bits CD; 128 words -> 7 bits.)
- Flynn taxonomy: SISD, SIMD, MISD, MIMD; complexity SISD < SIMD < MIMD (Multiprocessor = MIMD.)

QUESTION FAMILIES (most repeated first; each is a question type the exam keeps reusing)
- K-map simplification (7x): Plot minterms, group 1s in powers of 2 (largest groups, wrap-around), treat don't cares as 1 only if they enlarge a group, write each group as product of unchanged variables. Alternatively test each option by plugging minterms.
- Addressing modes facts and effective address (6x): Immediate: operand in instruction; direct: EA=address field; indirect: EA=M[address] (2 memory refs); register: 0 memory refs; indexed: EA=address+XR; register indirect: EA=R. Fastest = register/immediate.
- Two's complement representation and arithmetic (6x): -N in n bits = 2^n - N (invert and add 1). Overflow in addition iff both operands same sign and result sign differs. n-bit signed range -2^(n-1)..2^(n-1)-1. Subtraction = add 2's complement.
- Instruction cycle order (5x): Fetch instruction -> decode -> (calculate effective address) -> fetch operand -> execute. Check whether the option set includes the EA/operand steps; for register path PC->MAR->Memory->MBR->IR.
- Memory types and technology facts (5x): DRAM: slower, denser, cheaper, needs refresh; SRAM: faster, used for cache. CMOS chip on motherboard = ROM per the answer key; main memory = RAM+ROM; CAM = content search in parallel; access time definition.
- Boolean simplification and identities (5x): Apply absorption (x+xy=x), idempotent, domination, complement laws and XOR identities (A xor 1 = A', A xor 0 = A, A xor A = 0). Sum of A'B+AB'+AB = A+B.
- Memory capacity, address lines and chip count (4x): Capacity = 2^(address lines) x data lines. Address lines = log2(words). Chips = total bits / chip bits; byte-addressable vs word-addressable changes address bits.
- Memory hierarchy speed ordering (4x): Fastest to slowest: Registers > Cache (SRAM) > DRAM > SSD > Hard disk > Optical > Magnetic tape. Reverse for access time vs speed.
- Cache terminology and mapping (4x): Mappings: direct, associative, set-associative. Dirty bit = block modified after loading. Hit ratio is the key performance metric. Mapping = transforming main-memory blocks to cache lines.
- Counters (4x): Cascaded counters: states multiply (MOD-2 x MOD-5 = 10). JK with J=K=1 toggling with output clocking next = ripple (asynchronous). Ring counter N states; decade counter 0-9; synchronous = common clock.
- I/O transfer techniques (4x): Techniques: programmed, interrupt-driven, DMA (also IOP/channel). Handshaking uses two opposite control signals. I/O write = memory/CPU to device.
- Pipeline speedup and total time (4x): Pipelined time = (k+n-1) x clock (clock = max stage delay + register delay); non-pipelined = n x t. Speedup = n*t_np / ((k+n-1)*tp).
- 8085 instruction set and addressing (3x): Memorise 8085 categories: DAA arithmetic; LXI, MVI, MOV data transfer; JMP branch/program control; RST interrupt. Addressing: STA/LDA direct, MOV A,M register indirect, MOV A,B register, MVI immediate.
- Decoder, encoder and multiplexer functions (3x): Decoder n -> 2^n; encoder 2^n -> n (priority encoder resolves multiple inputs); mux 2^n -> 1; demux 1 -> 2^n. Half adder = 2-bit addition.
- Combinational versus sequential circuits (3x): Combinational: output depends on present input only, no memory, no feedback, no clock. Sequential: has memory/feedback, clocked. FF, counter, register sequential; mux, decoder, adder combinational.
- I/O procedure ordering (3x): Programmed input: read status register -> check flag -> read data register -> transfer to memory. DMA: request -> grant -> transfer -> release. Complexity order: I/O module < DMA < channel < I/O processor.
- Interrupt types and handling (3x): Internal (stack overflow, invalid opcode), external (timer, I/O), software (supervisor call), machine check. Handler address not fixed (vectored); dedicated interrupt request line.
- Number base conversion (3x): Group bits in 4s for hex, 3s for octal; fractional parts multiply by 2 repeatedly; negative fixed point = 2's complement of the positive pattern.
- Gray and BCD-type codes (3x): Gray: g = b xor (b>>1), successive codes differ by one bit. Self-complementing: 2421, excess-3 (not 8421).
- Amdahl's law speedup (3x): Speedup = 1/((1-f)+f/s). With p processors: T = serial + parallel/p.
- Multiprocessor architecture facts (3x): Multiprocessor: one OS, shared memory; multicomputer: separate computers on communication lines. NUMA: single address space, remote access via load/store and slower than local. Crossbar is non-blocking.
- Instruction format field widths (2x): Address bits = log2(words); register bits = log2(#registers); mode/indirect bit = 1; opcode = word length - all other fields.
- Basic computer program trace (2x): Execute line by line with Mano basic-computer semantics (CLA, ADD, INC, CMA, AND, BUN, STA); track AC in hex.
- Basic computer instruction type encoding (2x): Mano format: mode bit I + 3-bit opcode + 12-bit address. Opcode 000-110 = memory reference; I=0,opcode 111 = register reference; I=1,opcode 111 = I/O reference. Register-ref mnemonics: SZA, SNA, SPA, CLA, CMA, INC; I/O: SKI, SKO.
- RISC versus CISC (2x): RISC: load/store only memory access, fixed-length, single-cycle, pipelining friendly, hardwired. CISC: many addressing modes, variable length, microprogrammed.
- Direct-mapped cache address fields (2x): Address bits = tag + line/index + word offset. Offset = log2(block size), line = log2(#lines), tag = rest. Main memory = 2^(tag+index), cache = 2^index.
- Average memory access time (2x): T = h*Tc + (1-h)*Tm; for two levels apply recursively from the lowest level.
- Primary versus secondary memory statements (2x): CPU accesses primary memory directly, secondary only via I/O; primary holds active programs; secondary is backup/bulk storage.
- Cache coherence and write policies (2x): Write-through updates cache and memory; write-back updates cache only (dirty bit). Coherence solved by snoopy controllers or by not caching shared data.
- Complement of Boolean function (2x): De Morgan: complement = swap AND/OR and complement each literal (dual and complement variables).
- Logic gate properties (2x): NAND/NOR universal; XOR odd function (1 when odd number of 1s); XNOR output 1 for equal inputs; with inputs 00 NAND=1,NOR=1,XNOR=1,XOR=0. 2421 and excess-3 are self-complementing; buffer = amplification.
- Flip-flop basics (2x): Flip-flop stores one bit. SR: S=R=0 no change, S=R=1 invalid. Register = group of FFs.
- Interrupt service routine sequence (2x): ISR order: save registers -> check which flag is set -> service device -> restore registers -> turn interrupt facility on -> return.
- Isolated versus memory-mapped I/O (2x): Isolated: separate address space and special IN/OUT instructions. Memory-mapped: shares addresses and control signals with memory, uses normal load/store.
- Microinstruction format size (2x): Bits = sum of fields: each field ceil(log2 options); address field = log2(control memory words).
