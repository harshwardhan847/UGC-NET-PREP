FORMULAS AND FACTS
- Chomsky hierarchy: Regular ⊂ DCFL ⊂ CFL ⊂ CSL ⊂ Recursive ⊂ RE; Type3=FA, Type2=PDA, Type1=LBA, Type0=TM (Recursive sits between CSL and RE.)
- CFL closure: Closed: ∪, ·, *, reversal, homomorphism, ∩ regular. Not closed: ∩, complement, difference (CFL − regular is CF; CFL ∩ CFL is not.)
- Regular closure: Closed under all of union, concat, star, complement, intersection, reversal, homomorphism, quotient (L ∪ Σ* = Σ* regular.)
- Class closure: REC closed under complement; RE not closed under complement; regular* ∩ CFL is CFL (Compose upward in the hierarchy.)
- CNF form: A → BC or A → a; derivation of length-n string takes 2n-1 steps (Count n-1 binary + n terminal rules.)
- CNF conversion bound: (K-1)|P| + |T| (Per answer key of this question.)
- GNF: A → a α (terminal first then variables) (Do not confuse with CNF.)
- Ambiguity: Ambiguous iff some string has ≥2 parse trees ⇔ ≥2 leftmost derivations ⇔ ≥2 rightmost (More than one derivation alone is not ambiguity.)
- Pumping lemma (regular): w=xyz, |xy|≤p, |y|≥1, xy^i z ∈ L for all i≥0 (Only proves non-regularity.)
- Pumping lemma (CFL): w=uvwxy, |vwx|≤p, |vx|≥1, uv^i wx^i y ∈ L (Minimum |vx|=1.)
- Regex identities: φ+L=L; εL=L; φL=φ; (a*+b)*=(a+b)*; precedence star > concat > union (φL is φ, not L.)
- Arden theorem: R = Q + RP ⇒ R = QP* (P must not contain ε.)
- Moore/Mealy: Every Moore machine has an equivalent Mealy machine and vice versa (Both are FSMs with output.)
- PDA power: PDA = CFL; two stacks = TM; DPDA+prefix property ↔ LR(0) (One stack is not enough for a^n b^n c^n.)
- Decidability table: Regular: all decidable. CFL: membership, emptiness, finiteness decidable; equivalence, universality undecidable. CSL: membership decidable, emptiness undecidable. Recursive: membership decidable, emptiness undecidable (Common trap: CSL membership is decidable.)
- Rice theorem: Every non-trivial semantic property of L(M) is undecidable (Properties of M itself (e.g., bounded cells) can be decidable.)
- PCP: Undecidable in general; solve instances by matching strings (Check first/last symbols.)
- TM definitions: δ: Q×Γ→Q×Γ×{L,R}; multi-tape δ: Q×Γ^k→Q×Γ^k×{L,R,S}^k; recursive language = TM halts on all inputs (Recursive requires halting on rejected strings too.)
- Parser power: LR(0) < SLR < LALR(1) < CLR(1); LL(1) ⊂ LR(1); Yacc = LALR (LALR is weaker than CLR, stronger than SLR.)
- Bottom-up parsing: Reverse of rightmost derivation; scans left to right; stack+buffer+table (LL gives leftmost derivation.)
- FOLLOW: FOLLOW(X) ⊇ FIRST(β) for A→αXβ; if β nullable add FOLLOW(A) (ε never in FOLLOW; $ for start symbol.)
- LR item: A → ε yields item A → · (GOTO moves dot then closes.)
- Quadruple count: One quadruple per operator (Expression (i*j)+(e+f)*(a*b+c) has 6.)
- Basic block leaders: First instruction; target of any jump; instruction immediately after a jump (Middle instruction is not a leader.)
- Compiler phases order: Lexical → syntax → semantic → intermediate code → optimisation → code generation (Semantic analysis does type checking.)
- Constant folding: Compile-time evaluation of constant expressions (Not strength reduction.)
- L* membership: Parse into {ab,aa,baa} blocks greedily (Check a-run parity.)

QUESTION FAMILIES (most repeated first; each is a question type the exam keeps reusing)
- CFL closure properties (union yes, intersection/complement no) (9x): Memorise the table: CFL closed under union, concatenation, star, reversal, homomorphism, intersection with regular; NOT under intersection, complement, difference. Counterexample is a^n b^n c^n = (a^n b^n c^m) ∩ (a^m b^n c^n).
- Chomsky hierarchy: types, automata, production forms, containment (7x): Type3=regular=FA, Type2=CFG=PDA, Type1=CSG=LBA, Type0=RE=TM. Regular ⊂ CFL ⊂ CSL ⊂ Recursive ⊂ RE. Type-3 is the only epsilon-free type by form.
- Ambiguity: identify ambiguous grammars, definition, dangling else (7x): Ambiguous iff some string has two parse trees (equivalently two leftmost or two rightmost derivations). Test the grammar with SS, SbS, or asbs patterns; if/else with unmatched else is ambiguous. Palindrome-like wwR is not inherently ambiguous; aⁿbⁿcᵐ ∪ aⁿbᵐcᵐ is.
- Intermediate code, SDT and syntax-tree uses (7x): Forms: syntax tree, DAG, postfix, three-address code (quadruples, triples, indirect triples). SDT used for type checking, syntax tree, TAC; quads count = operators.
- June 2025 TAC passage: leaders, flow graph, dominators, optimisation (6x): Leaders: first instruction, targets of jumps, instruction after a jump. Build blocks leader to leader, draw edges, derive dominators.
- CNF/GNF form and derivation-length facts (5x): CNF rules: A→BC or A→a. Derivation of a string of length n in CNF takes 2n-1 steps. Conversion bound (K-1)|P|+|T|. GNF: A→aα.
- What language does this grammar generate / string property (5x): Expand productions symbolically, find the invariant (parity, ordering, lengths) and test short strings against options.
- Dec 2024 passage: automata for strings containing abb (5x): Strings over {a,b} containing abb: DFA with 4 states, final state absorbing; regex (a+b)*abb(a+b)*; grammar S→AabbA, A→aA|bA|ε. Check option by testing abb, ab, aabb.
- Count states/final states in (minimal) DFA (5x): Unary multiples of n: n states (the answer key shows n+1 for a particular form). Minimal DFA via table filling; merge states with equal outputs. Counts for n-state automata: initial 1, final 0..n.
- Read an automaton: language, regex, equivalence (5x): Track parity/pattern state; for regex use state elimination or Arden R=Q+RP gives Q P*. Equivalence: minimise both and compare.
- NFA/DFA/epsilon-NFA conceptual facts and conversion (5x): NFA and DFA recognise the same class; epsilon-closure for shortest string; equivalent machines accept the same language; construction order: problem, regex, NFA-ε, DFA, min DFA.
- Pumping lemma statements and non-regular languages (5x): Regular PL: |xy|≤p, |y|≥1. CFL PL: |vx|≥1, |vwx|≤p. Languages needing unbounded comparison (n≠k, a^(n+k) with ordering, square lengths, ww) are not regular; a^(n^2) is not regular too.
- Parser power ordering and parser types (5x): LR(0) < SLR < LALR < CLR(1); LL(1) and recursive descent are top-down; LR family bottom-up; Yacc generates LALR(1); operator precedence is weakest bottom-up.
- Shift-reduce parser basics (derivation, scan order, conflicts, stack configuration) (5x): Bottom-up = rightmost derivation in reverse, scans left to right, uses stack, input buffer, table; conflicts resolved by precedence/associativity.
- Decidability per language class (5x): Regular: all decidable. CFL: membership/emptiness/finiteness decidable, equivalence/universality undecidable. CSL: membership decidable, emptiness undecidable. Recursive: membership decidable, emptiness undecidable.
- TM design passage a^n b^m c^n d^m transitions (5x): Mark one a with X1 then move right to matching c, mark with X2; error entries are transitions that move into a wrong symbol class. Track which mark each state seeks.
- TM basics: definition, transition function, language from δ (5x): Single-tape δ: Q×Γ→Q×Γ×{L,R}; multi-tape adds k tapes and S. Recursive = halts on all inputs. TM exists for every regular and CF language. aⁿbⁿ marking machine includes n≥1.
- Closure/regularity of regular-language operations (quotient, homomorphism, reversal, union with L*) (4x): Regular languages are closed under every standard operation; apply the operation to the DFA/regex (substitute symbols for homomorphism, reverse arrows for reversal). L ∪ A* = A* is regular.
- Classify a language with counting constraints (CF vs not CF vs CSL) (4x): One counter (a^n b^n, n_a+n_b=n_c, a^(n+m) b^n a^m) is CF; two independent equalities across three or more blocks (a^n b^n c^n, i=j=k) are not CF but CSL. Check by whether one stack can match all dependencies.
- Compiler phases and their roles (4x): Order: lexical, syntax, semantic, intermediate code, optimisation, code generation. Semantic analysis does type checking/conversion; symbol table holds identifiers and attributes.
- Decidability: Rice theorem and TM undecidable problems (4x): Any non-trivial property of L(M) is undecidable (equivalence, emptiness, finiteness, regularity). Halting is undecidable. Properties of the machine code itself or bounded simulation are decidable.
- Construct or compare grammars for a given language (3x): Test each option grammar on the shortest strings of the language (and a string that must be excluded). For equivalence, compare the sets generated by recursion (SS and λ closure).
- PDA language from transitions (3x): Trace stack effect: pushes per a, pops per b gives ratio language (push 3 pop 1 gives a^n b^3n; 11 per a gives a^2n b^n). Start-state epsilon move to final adds the empty string (n≥0 vs n>0).
- Automata power facts (PDA, multi-stack, grammar types recognised) (3x): PDA recognises CFL (and regular); two stacks = TM; DPDA with prefix property corresponds to LR(0).
- CFG simplification and decision on CFL (reduced grammar, order, finiteness) (3x): Order: remove epsilon, then unit, then useless (non-generating before unreachable). Finiteness of CFL decided on non-redundant CNF grammar of L-{Λ} by looking for a cycle.
- Identify grammar type / form of productions (3x): Classify by LHS and RHS shape: single non-terminal LHS = CF; right-linear = regular; A→BC|a = CNF; LL(1) grammars parsable by recursive descent.
- Regex containment and equivalence (3x): Rewrite each regex as a description set; (a*+b)*=(a+b)*; s=aa*b ⊂ a*b; a(a+b)+ ⊂ a(a+b)*. Check inclusion by sample strings.
- Regex algebra and writing a regex for a language (3x): φ+L=L, εL=L, φL=φ; precedence star > concatenation > union. For a^n b^m with bounds, write a^4 a* (λ+b+bb+bbb).
- LR items, handles and GOTO (3x): A→ε yields item A→·; GOTO(I,X) moves dot over X then closure; handle is the leftmost simple phrase reduced at each step.
- Code optimisation concepts (3x): Constant folding = compile-time evaluation; loops identified by dominators, depth-first order, reducible graphs.
- Language-class closure matching (complement/union/intersection of REC, RE, CF, regular) (2x): Use: REC closed under complement and union; RE closed under union but not complement; complement of CFL is only recursive (CSL); regular* ∩ CFL is CFL. Compose upward.
- Membership of strings in L* for L={ab,aa,baa} (2x): Greedily parse into blocks ab, aa, baa; a string fails if some a-run leaves a dangling single a or b start that cannot be matched.
- LL(1)/FOLLOW computation (2x): FOLLOW(X) = FIRST of what comes after X; if nullable add FOLLOW of the parent. LL(1) requires unambiguous grammar with no left recursion and disjoint FIRST.
- Post correspondence problem instances (2x): Look for a sequence where concatenations from both lists match; check length balance and first/last symbols. PCP in general is undecidable.
