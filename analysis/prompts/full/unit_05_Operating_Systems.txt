FORMULAS AND FACTS
- Deadlock-free process bound: R >= n(m-1)+1, so n_max = floor((R-1)/(m-1)) (R resources, each process needs m; e.g. R=12,m=4 gives 3)
- Banker: Need: Need = Max - Allocation; safe if some order lets every process finish with Available (In dec2019_q28 'Current needs' column is actually the allocation)
- Disk capacity: surfaces x tracks per surface x sectors per track x bytes per sector (Double-sided platters have 2 surfaces each)
- Sector-address bits: log2(surfaces x tracks x sectors) (Count total sectors, then bits)
- Rotational delay: max = 60/rpm seconds; average = half of that (5400 rpm gives 11.1 ms)
- Data transfer rate: bytes per track x revolutions per second (One track per revolution)
- Seek time: total head movement x time per cylinder (SSTF picks nearest pending request each time)
- Disk policies: SCAN goes to end then reverses; C-SCAN goes to end then jumps to start; LOOK/C-LOOK turn at the last request (C-SCAN return jump counted in textbook answers)
- Inode maximum file size: (direct + p + p^2) x block size, p = block size/address size (2KB blocks,4B addresses: p=512, about 513 MB)
- Tape write time: (data / recording density) / speed (+ inter-block gaps) (600000/1600/200 = 1.875 s)
- Paging sizes: pages = VA/page size; offset bits = log2(page); frames = PM/page; page table size = pages x entry size (Physical address bits = log2(PM size))
- Internal fragmentation: unused space in last page = pages x page size - process size (34 KB with 4 KB pages gives 2 KB)
- EMAT with TLB: h(t+m) + (1-h)(t+2m) (Single level page table; two-level adds extra m)
- EAT with page faults: (1-p)m + p x fault time; or p + q/100 if one fault per 100 (Hit ratio form h*t1 + (1-h)*t2)
- Swap time: 2 x (size/transfer rate) + latencies (15MB/30MBps=0.5s each way)
- Belady's anomaly: Occurs for FIFO; LRU and optimal are stack algorithms and have no anomaly (Common trap in statement questions)
- Little's law: n = lambda x W (20 = 10 x W gives 2 s)
- Scheduling times: TAT = CT - AT; WT = TAT - BT; RT = first run - AT; HRRN ratio = (W+S)/S (Weighted TAT = TAT/burst)
- RR worst-case wait: (n-1) x q (20 processes, q=4 gives 76 ms)
- Counting semaphore: final = initial - #P + #V (Solve for unknown #V)
- fork count: k sequential forks create 2^k processes (Count prints by tracing each fork)
- RAID levels: 0 striping,1 mirror,2 bit ECC,3 bit parity,4 block parity,5 distributed block parity,6 P+Q (Level 1 for write-heavy logs)
- Linux interrupt priority: user < kernel system service < bottom half < top half (Exact repeat)
- Thread sharing: Shared: code,data,files,address space. Private: stack,registers,PC (Threads of same process share address space)
- Thread model concurrency: one-to-one > many-to-many > many-to-one (Many-to-one blocks entirely on a blocking call)
- Boot order: ROM firmware -> boot block -> bootstrap loader -> kernel (Ordering trap)
- Layered file system: Application -> logical FS -> file organization module -> basic FS -> I/O control (Top to bottom)
- File allocation: Contiguous has external fragmentation; linked and indexed do not (Indexed supports direct+sequential access)
- Compiler phase order: lexical, syntax, semantic, intermediate code, optimization, code generation (Hash table best for symbol table)
- Unix facts: fork creates child; exec loads program; kill signals; clone selective sharing; wc -l; lpr; /etc/passwd; chmod -R a+x (Single-fact recall)

QUESTION FAMILIES (most repeated first; each is a question type the exam keeps reusing)
- Paging address arithmetic (pages, frames, offset, page table size, internal fragmentation) (7x): pages = VA size/page size; offset bits = log2(page size); frames = PM size/page size; PT size = pages x entry size; internal fragmentation = unused part of last page.
- Count page faults on a reference string (FIFO / LRU / Optimal) (6x): Simulate frames in a table; FIFO evicts oldest loaded, LRU least recently used, Optimal the page used farthest in future. Count misses.
- Disk capacity / geometry arithmetic (5x): capacity = surfaces x tracks x sectors/track x bytes/sector; cylinders = tracks per surface; sector-address bits = log2(total sectors).
- June 2023 passage: column-major vs row-major array traversal under LRU (5x): Pages hold rows of 1024 entries per page; column-wise traversal of 17 rows with 17 or fewer frames: count faults per column vs row-wise: 17 faults once, then hits.
- Preemptive SJF / SRTF waiting or turnaround time (5x): Draw the Gantt chart; at every arrival compare remaining times. TAT = CT - AT; WT = TAT - BT.
- Process model basics (states, queue, PCB, heap, cascading termination) (5x): Running can go to ready (timer), waiting (I/O); ready queue holds ready processes in memory; PCB holds state, registers, scheduling info (not code); heap = dynamic memory; cascading termination.
- Mutual exclusion and critical-section statements (5x): Only one process in critical section; structure entry/critical/exit/remainder; spin lock = busy waiting; unaware processes still have mutual exclusion, starvation, deadlock problems but not coherence.
- Banker's algorithm passage (5x): Banker avoids deadlock; needs Max, Allocation, Available matrices/vectors; grants only if the system stays in a safe state.
- SSTF seek-time/head-movement on a request queue (4x): Sort out nearest-first order: from the head repeatedly pick the pending request with smallest |difference|; add the gaps (multiply by ms per cylinder if asked). Draw the visiting order on one line.
- Total head movement for FCFS / SCAN / C-SCAN / C-LOOK (4x): FCFS = sum of consecutive gaps. SCAN goes to the disk end then reverses; C-SCAN goes to the end then jumps to 0 (jump counted in the usual textbook answer) and continues; LOOK/C-LOOK turn at the last request, not the disk end.
- RAID level matching (4x): Memorise: 0 striping, 1 mirroring, 2 bit-level ECC (memory-style), 3 bit-interleaved parity, 4 block-interleaved parity, 5 block-interleaved distributed parity, 6 P+Q / Reed-Solomon.
- Unix/Linux command facts (4x): wc -l counts lines; chmod -R a+x; lpr prints; user passwords/accounts in /etc/passwd; glob *.[ch].
- Match-the-following of OS terms (4x): Link each term to its area: Banker = resource allocation, demand paging = virtual memory, LFU = cache replacement, critical section = mutual exclusion, firmware = ROM, PCB = TCB, IPC = computational speedup.
- Non-preemptive FCFS / SJF / HRRN metrics on one process set (4x): FCFS by arrival; SJF picks the smallest burst among arrived processes; HRRN ratio = (W+S)/S. Weighted turnaround = TAT/burst.
- Scheduling theory statements (starvation, response time, quantum) (4x): SRTF and priority may starve; HRRN/aging fixes starvation; RR gives better response than FCFS; tiny quantum means many context switches.
- Thread concepts and models (4x): Threads share code, data and files but have own stack and registers; user library creates threads; concurrency one-to-one > many-to-many > many-to-one.
- Counting semaphore value after P and V operations (4x): final = initial - (#P) + (#V).
- Identify the 2nd request served / the policy from a head graph (3x): Trace the policy order on the same queue: C-LOOK(right) serves increasing requests then jumps to the lowest; SCAN(left) serves decreasing requests first. For a graph, look for a jump back without touching the disk end = C-LOOK.
- Virtual memory conceptual statements (3x): Virtual memory increases effective capacity; program can be larger than RAM; not all pages need to be loaded; address translation for every logical address.
- Process-creation system calls (fork, exec, clone, kill, exit) (3x): fork creates child; exec loads new program; kill sends signal; exit terminates; clone gives selective sharing flags (Linux).
- Round-robin waiting/turnaround and maximum wait (3x): Simulate the queue with quantum q; waiting = completion - arrival - burst; worst-case wait for n processes = (n-1)q.
- Rotational delay and data-transfer rate (2x): max rotational delay = 60/rpm s (avg = half); transfer rate = bytes per track x revolutions per second.
- File allocation methods and fragmentation (2x): Contiguous: external fragmentation, fast direct access. Linked: no external fragmentation, no direct access, pointer space. Indexed: direct + sequential, no external fragmentation, index-block overhead.
- Effective access time with TLB (2x): EMAT = h(t+m) + (1-h)(t+2m) for single-level paging (t = TLB time, m = memory time).
- Logical / virtual / physical address terminology (2x): Address in main memory = physical address; CPU-generated = logical (virtual); address space = logical/virtual set, memory space = physical set.
- Effective access time with page faults / hit ratio (2x): EAT = (1-p)*m + p*(fault service time); with hit ratio h: h*t_primary + (1-h)*t_secondary.
- Order of page-replacement steps (2x): Find page on disk; if no free frame use algorithm to pick victim, write it back if dirty, update tables; read in desired page; restart instruction.
- Linux interrupt protection level ordering (2x): Increasing priority: user mode < kernel system service routines < bottom half handlers < top half handlers.
- I/O protection and interrupts (2x): I/O instructions are privileged; with memory-mapped I/O protection is by the OS (memory protection); I/O completion interrupts are different from a trap for protection.
- Priority scheduling average waiting / response time (non-preemptive) (2x): Order by priority (lower number first), then cumulative start times give waiting times.
- Preemptive vs non-preemptive circumstances (2x): Preemption happens when running->ready or waiting->ready; non-preemptive SJF never context-switches mid-burst.
- OS-specific scheduling (Windows, Linux) (2x): Windows 16 non-real-time priorities (and 16 real-time); Linux supports preemptive priority and time-sharing.
- Maximum processes for deadlock freedom (2x): Deadlock-free if R >= n(m-1)+1, so n_max = floor((R-1)/(m-1)).
- Symbol table (2x): Symbol table used for storage allocation, type checking, duplicate-error suppression; hash table gives fastest access.
- Compiler phases order and roles (2x): Lexical -> syntax -> semantic -> intermediate code -> optimization -> code generation; syntax analysis checks grammar.
