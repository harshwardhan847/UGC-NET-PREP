FORMULAS AND FACTS
- Master theorem: T(n)=aT(n/b)+f(n): f<n^log_b a -> theta(n^log_b a); f=n^log_b a -> theta(f lg n); f>n^log_b a (regularity) -> theta(f) (2T(n/4)+sqrt n -> sqrt n lg n (equal case); 3T(n/4)+n lg n -> n lg n (case 3).)
- Constant-work shrink: T(n)=T(cn)+1 -> theta(lg n) for 0<c<1 (T(3m/4)+1 and T(2n/3)+1 are both lg.)
- sqrt recurrence: T(n)=aT(sqrt n)+f(lg n): let m=lg n -> S(m)=aS(m/2)+f(m) (2T(sqrt n)+lg n -> O(lg n lg lg n); 4T(sqrt n)+lg^2 n -> theta(lg^2 n lg lg n).)
- Growth chain: lg n < sqrt n < n < n lg n < n^1.5 < n^2 < n^lg n < 2^n < n! (n^lg n is superpolynomial but below 2^n.)
- Worst/best-case O: Algorithm is O(g) iff worst case O(g); f=O(g) <=> g=Omega(f); little-o and little-omega transitive (O and o are not interchangeable; f=O(g) does not give omega.)
- Sort/search complexities: binary search lg n; insertion best n worst n^2; merge n lg n; quick avg n lg n worst n^2; heap n lg n; selection n^2 (Insertion sort best case linear.)
- Graph algorithm complexities: Dijkstra V^2 (heap E lg V); Prim E lg V; Kruskal E lg E; Bellman-Ford VE; Floyd-Warshall V^3; toposort/BFS/DFS V+E; Edmonds-Karp VE^2; Ford-Fulkerson E*f (Kruskal sometimes written O(E lg V) - same.)
- Edge relaxation: d[v] = min(d[v], d[u]+w(u,v)) (Updated value 27 from 29 vs 15+12.)
- Fractional knapsack: Sort by p/w descending; take whole items then fraction of next; time O(n lg n) (0/1 knapsack needs DP; fractional is greedy.)
- LCS recurrence: c[i,j]=c[i-1,j-1]+1 if x_i=y_j else max(c[i-1,j],c[i,j-1]) (Subsequence need not be contiguous.)
- Huffman: Merge two least weights repeatedly; average length = sum p_i*len_i; weighted path length = sum of all merged internal node weights (Probabilities 0.08,.40,.25,.15,.12 give 2.15.)
- DP steps: Characterize structure -> define recursively -> compute bottom-up -> construct solution (Only step 1 is shared with greedy.)
- FFT: Multiply degree-n polynomials in theta(n lg n); point-value product theta(n); Horner evaluation at n points theta(n^2) (Parallel FFT span theta(lg n).)
- Full m-ary tree: L=(m-1)*I+1; total nodes = m*I+1 (41 leaves, 10 internal -> m=5.)
- Strict binary tree: n = 2L-1 nodes; internal = L-1 (19 leaves -> 37 nodes exactly.)
- Degree-sum leaves: L = 1 + sum over internal nodes (degree-1) (Ternary: 4*0+3*1+3*2+1=10.)
- Catalan number: Binary trees with n nodes = C(2n,n)/(n+1) (Not 2^n-1.)
- Heap facts: Build-heap theta(n); heapify O(lg n); nodes of height h <= ceil(n/2^(h+1)); min of max-heap lies in leaves O(n) (Insert = sift up.)
- B-tree: height h <= log_t((n+1)/2); order M node: M-1 keys, M pointers; worst-case insert creates h+1 new nodes (4 levels -> 5 new nodes.)
- Red-black / AVL: RB: longest path <= 2x shortest, height <= 2 lg(n+1); AVL: |balance|<=1; 2-3-4 tree <-> red-black (AVL more rotations, tighter balance.)
- Traversals: Inorder L,Root,R; unique tree from preorder+inorder or postorder+inorder (Preorder first element is root.)
- Postfix/prefix: Postfix: scan left-right, pop 2 (second popped is left operand). Prefix: scan right-left. Operand order same in infix/postfix (Prefix is not simply reverse of postfix.)
- Circular queue: Capacity n-1 in array n; empty: front==rear; full: (rear+1) mod n == front (One slot sacrificed.)
- Double hashing: h(k,i) = (h1(k) + i*h2(k)) mod m; probe difference = h2(k) (123456 -> 257.)
- Universal hashing: m=n^2 slots, n keys: P(any collision) < 1/2 (Expected collisions < C(n,2)/m.)
- Radix sort cost: d digits, radix k: theta(d(n+k)); integers in 0..n^2-1 sort in O(n) (9*5*8=360.)
- Second smallest: n + ceil(lg n) - 2 comparisons (tournament) (Worst case.)
- NP facts: NPC in P => P=NP; NPC = NP intersect NP-hard; P subset of co-NP; NP != co-NP => P != NP; vertex cover 2-approx; TSP triangle-inequality 2-approx (EXP = 2^(n^k), not 2^k.)
- Fibonacci methods: naive recursion exponential; memoised O(n); matrix/doubling O(lg n) (Matching question.)

QUESTION FAMILIES (most repeated first; each is a question type the exam keeps reusing)
- Balanced tree concepts (AVL, RB, B, 2-3-4) (8x): AVL: strict balance, more rotations; RB: longest path <= 2x shortest, O(lg n); 2-3-4 tree equivalent to red-black; B-tree for disk; AVL rotations LL RR LR RL.
- Master theorem and simple recurrences (6x): Compare f(n) with n^(log_b a): smaller -> n^log_b a; equal -> times log n; larger -> f(n). For T(n)=T(cn)+1 get log n.
- Fractional knapsack passage (Dec 2022) (5x): Compute p/w ratios, sort descending, fill greedily, take a fraction of the last item that does not fit. Greedy is optimal for fractional, not for 0/1.
- Classify problems by design paradigm (5x): Memorise the paradigm table: greedy (Dijkstra, Kruskal, Prim, Huffman, fractional knapsack), DP (Bellman-Ford, LCS, edit distance, OBST, 0/1 knapsack, Floyd), D&C (merge, quick, binary search, Strassen, closest pair), backtracking (8-queens).
- Asymptotic growth ordering (5x): Take logs or substitute big n; known chain: log n < sqrt n < n < n log n < n^1.5 < n^2 < n^log n < 2^n < n!.
- Match algorithms to running times (sort/search/DP/AI) (5x): Recall table: insertion best O(n), binary search O(lg n), quick avg n lg n worst n^2, heap n lg n, Rabin-Karp theta((n-m+1)m), Fibonacci naive exponential, memoised O(n), matrix-power O(lg n), hill climbing O(1), DFS O(bm), A*/BFS O(b^d), D&C recurrences.
- Match graph algorithms to time complexities (5x): Dijkstra O(V^2) (array) / O(E lg V) (heap); Prim O(E lg V); Kruskal O(E lg E); Bellman-Ford O(VE); Floyd-Warshall theta(V^3); toposort theta(V+E); Edmonds-Karp O(VE^2).
- NP-class statements (5x): Use: NPC subset of NP and NP-hard; one NPC in P implies P=NP; SAT/CIRCUIT-SAT/Hamiltonian/TSP-decision are NPC; P subset of co-NP.
- Tree counting identities (5x): m-ary full: L=(m-1)I+1; strict binary: n=2L-1; degree sum: L=1+sum (d-1)*n_d; leaves of complete binary tree = i+1.
- DP development steps and properties (4x): Order: characterize optimal structure, recursive definition, compute bottom-up, construct solution. Only optimal-substructure is shared with greedy. Cyclic dependency breaks DP.
- Infix to postfix conversion (4x): Stack of operators: pop while top has >= precedence (not for right-assoc ^); parentheses group; operands emitted immediately.
- MST by hand (Prim/Kruskal) (4x): Kruskal: sort edges, add if no cycle. Prim: grow from start picking min edge to new vertex. MST weight is same.
- Heap and priority-queue operation costs (4x): Build-heap O(n); heapify/insert/extract O(lg n); min in max-heap O(n); unsorted-array PQ insert O(1), extract-min O(n); heap cannot do dedup in O(lg n).
- Huffman coding computations and steps (3x): Repeatedly merge the two smallest weights; average length = sum(p*depth); weighted path length = sum of internal merge costs. Steps: leaves, priority queue, combine lowest, repeat.
- FFT polynomial multiplication / FFT complexities (3x): FFT evaluates and interpolates in O(n lg n); pointwise product O(n); so multiplying degree-n polynomials is theta(n lg n).
- Queue/stack variants and applications (3x): Know applications: circular queue-CPU scheduling, priority queue-Dijkstra, deque-palindrome check, queue-print, BFS-queue, DFS-stack, prefix-LISP, infix-syntax tree.
- Asymptotic notation properties (3x): Check definitions: O,Omega transitive; o,omega transitive; algorithm O(g) iff worst O(g); f=O(g) implies g=Omega(f).
- Postfix/prefix evaluation (3x): Postfix: left to right, push operands, apply on two pops (second pop is left operand). Prefix: right to left.
- Graph algorithm purpose and properties (3x): Dijkstra: non-negative weights, single-source; Bellman-Ford: negative edges; Floyd/Warshall: all pairs/path matrix; Prim/Kruskal: MST. Shortest path need not have fewest edges.
- BFS/DFS properties and applications (3x): DFS: toposort, SCC; no cross edges in undirected DFS tree; BFS tree edges can join same level. Prim/Dijkstra are best-first, not BFS.
- Hash insertion simulation (3x): Compute h(x) for each key and probe forward to the next empty slot.
- Collision resolution definitions (3x): Chaining=linked list; linear=next slot; quadratic=skip by squares; double=second hash; hash table backed by array.
- B-tree computations (3x): Height h <= log_t((n+1)/2); node size = keys*key size + pointers*size; insertion worst case splits every level (+1 new root).
- Tree traversals (3x): Inorder L-Root-R; reconstruct from preorder+inorder (root first from preorder, split inorder).
- Longest common subsequence (2x): Fill LCS table: match -> diag+1 else max(up,left); read the sequence by backtracking.
- Recurrences with sqrt(n) (substitution n=2^m) (2x): Set m = lg n, S(m)=T(2^m); T(n)=aT(sqrt n)+f becomes S(m)=aS(m/2)+f(m), then master theorem.
- Is this sequence a valid DFS? (2x): Walk the sequence: each next vertex must be adjacent to a vertex still on the DFS stack path (go back only when stuck).
- Max-flow facts (2x): Flow: skew symmetry f(u,v)=-f(v,u) and conservation sum_v f(u,v)=0; Ford-Fulkerson O(E*f) for integer capacities.
- Linear probing: location of key 18 (exact repeat) (2x): Insert in order with h=key mod 7, move to next free slot on collision; 18 lands at index 5.
- Stability and in-place properties of sorts (2x): Stable: bubble, insertion, merge. In-place: insertion, heap, quick.
- Linear-time and radix sorting (2x): Radix sort on d-digit numbers: O(d(n+k)); range n^2 -> two passes base n -> O(n). Count-based answer: items x digits x radix.
- Build heap / insert into heap by hand (2x): Max-heapify from n/2 down (build) or sift-up on each insertion; write array.
- BST build and measure (2x): Insert keys in order, then count left-subtree nodes or measure height (edges).
