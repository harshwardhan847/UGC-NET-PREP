FORMULAS AND FACTS
- Transmission delay: Tt = frame size (bits) / bandwidth (bps) (Convert bytes to bits first.)
- Propagation delay: Tp = distance / propagation speed (Watch units: km vs m, us per km vs km/s.)
- Bandwidth-delay product: BDP = bandwidth x delay (RTT if round trip given) (Result in bits.)
- Optimal sliding-window size: W = 1 + 2Tp/Tt (Sequence bits n: window <= 2^n - 1 (go-back-N) or 2^(n-1) (SR).)
- Sliding-window efficiency / throughput: efficiency = W / (1 + 2Tp/Tt) capped at 1; throughput = efficiency x bandwidth (Throughput cannot exceed link rate.)
- Error detection/correction distance: Detect s errors: d_min = s + 1; correct t errors: d_min = 2t + 1 (Mixing the two is the usual trap.)
- Hamming distance: Number of bit positions where two words differ (weight of XOR) (Decode to nearest valid codeword.)
- CRC codeword: Codeword = dataword || remainder (remainder from modulo-2 division after appending zeros) ((x+1) factor of G(x) catches all odd-bit errors (nov2021_q100).)
- Bit stuffing flag: Frame flag 01111110 = 0x7E; stuff 0 after five consecutive 1s (Flag is hex 7E.)
- Nyquist bit rate: C = 2B log2(L) (Noiseless channel only; sampling rate >= 2 f_max.)
- Shannon capacity: C = B log2(1 + SNR) (Noisy channel; SNR is a ratio, not dB.)
- Frequency and period: f = 1/T (100 ms = 10 Hz = 10^-2 kHz.)
- Fully connected links: n(n-1)/2 (Symmetric keys for N persons also N(N-1)/2 (dec2018_q90).)
- CSMA/CD minimum frame: L_min = bandwidth x 2Tp (Round-trip time, not one way.)
- Slotted ALOHA throughput: S = G e^(-G); pure ALOHA S = G e^(-2G) (G = frames per frame time.)
- Token bucket burst duration: T = C / (M - rho) = capacity / (output rate - token rate) (16/(10-2) = 2 s.)
- Token ring 1-bit delay: distance per bit = propagation speed / bit rate (200 m/us / 10 Mbps = 20 m.)
- Hosts per subnet: 2^(host bits) - 2; subnets = 2^(subnet bits) (Subtract 2 for network and broadcast addresses.)
- Subnetting a block: new prefix = old prefix + log2(subnets); addresses = 2^(32 - prefix) (1024 subnets from /16 gives /26 and 64 addresses.)
- IPv4 class ranges: A 0-127, B 128-191, C 192-223, D 224-239, E 240-255; A=50%, B=25%, C=12.5% of space (127.x.x.x loopback is class A.)
- IP fragmentation: data per fragment = floor((MTU - 20)/8)*8; offset = bytes/8 (MTU 820 gives 800 data bytes.)
- IPv4 header decode: byte0 low nibble HLEN x 4; bytes 2-3 total length; byte 8 TTL; byte 9 protocol (6 TCP, 17 UDP, 1 ICMP) (Efficiency = (total - header)/total.)
- RSA: n = pq; phi = (p-1)(q-1); ed = 1 mod phi; C = M^e mod n; M = C^d mod n (Private-key encryption gives digital signature.)
- Symmetric key count: N(N-1)/2 keys for N parties (Public-key needs only N key pairs.)
- Cipher sizes: DES 64-bit block/56-bit key; 3DES 168; AES 128 block, 128/192/256 key; IDEA 64/128; Blowfish 32-448 (DES has 16 rounds; function steps: expansion, XOR key, S-box, P-box.)
- Line coding average bandwidth: NRZ-L N/2; MLT-3 N/3; 2B1Q N/4; 4D-PAM5 N/8; Manchester bit rate = half baud (Manchester needs twice the bandwidth of NRZ.)
- DHCP sequence: Discover, Offer, Request, Ack (Renewal: timer, request, ack.)
- Hierarchical routing table size: entries = routers in own region + other regions in cluster + other clusters (Key gives 25 for the 720-router example.)
- Piconet: 1 master + up to 7 active slaves (Scatternet joins piconets.)

QUESTION FAMILIES (most repeated first; each is a question type the exam keeps reusing)
- OSI layer function matching and ordering (8x): Physical: raw bits; Data link: frames, MAC, piggybacking; Network: routing, logical address, billing; Transport: end-to-end, segmentation; Session: dialog/token mgmt; Presentation: syntax; Application: user interface.
- Sliding-window passage and throughput calculation (6x): Tt = frame bits/rate; Tp = distance x delay per km; optimal window W = 1 + 2Tp/Tt; efficiency = min(1, W_given/W_opt); throughput = efficiency x rate; sequence bits n with 2^n - 1 >= window (go-back-N style).
- IPv4 header hex decoding (6x): Hex 45 00 0054 ...: first nibble version, second HLEN (x4 bytes), bytes 3-4 total length, byte 9 TTL, byte 10 protocol (06 TCP, 11 UDP, 01 ICMP); efficiency = (total - header)/total.
- Subnetting passage (130.56.0.0/16 into 1024 subnets) (5x): Subnet bits = log2(subnets); new prefix = old + bits; addresses per subnet = 2^(32-prefix); first = block base, last = base + size - 1; last subnet = top of the parent block.
- IPv4 classes, ranges and special addresses (5x): Class first octets: A 0-127 (loopback 127), B 128-191, C 192-223, D 224-239, E 240-255. Class A is 1/2 of space, B 1/4, C 1/8 (12.5%).
- Subnet mask and host/subnet counting (5x): Hosts per subnet = 2^(host bits) - 2; subnets = 2^(subnet bits) (minus 2 in old classful convention as in nov2021_q95); AND address with mask to compare networks.
- Symmetric cipher block and key sizes (5x): DES 64-bit block, 56-bit key; 3DES 168; IDEA 64/128; Blowfish 64/32-448; AES 128 block, keys 128/192/256; RSA key about 1024+; RC4 is stream.
- Public-key, hash and digital-signature concepts (5x): Encrypt with receiver public key for secrecy; sign by encrypting hash/digest with sender private key; hash gives fixed-length digest; AES symmetric, RSA asymmetric.
- Which layer does what (PDU names, encryption, segmentation) (5x): PDUs: frame (link), packet (network), segment (transport). IP is host-to-host, TCP process-to-process. Encryption is presentation/application. Session: dialog control, token management, synchronization.
- Hamming distance and error detection/correction capacity (4x): Detect s errors: d_min = s+1; correct t errors: d_min = 2t+1; Hamming distance = number of differing bit positions; decode to nearest valid codeword.
- MAC protocol classification and multiple-access facts (4x): Random access: ALOHA, CSMA (1-persistent, non-persistent, p-persistent), CSMA/CD wired, CSMA/CA wireless. Controlled: reservation, polling, token passing. Channelization: FDMA, TDMA, CDMA (orthogonal codes).
- Line coding schemes (4x): Average bandwidth: NRZ-L N/2, MLT-3 N/3, 2B1Q N/4, 4D-PAM5 N/8; Manchester is self-clocking with two signal elements per bit; NRZ, Manchester, AMI are encodings; Hamming code is not a line code.
- Cloud service models and virtualization (4x): SaaS software stack; PaaS development environment; IaaS infrastructure; hypervisor then VMs then resources then workloads; Azure OS-like platform, CloudFront CDN.
- Order of steps in a web/DNS request (3x): Browsing order: URL typed, local DNS cache/resolver, root, TLD, authoritative, IP obtained, TCP SYN, HTTP GET, page displayed. DNS always precedes TCP and HTTP.
- WAN link protocols (PPP, Frame Relay, X.25) facts (3x): Frame relay frame: Flag, Address, Information, FCS, Flag; frame relay detects errors but gives no ack/flow control; PPP gives framing, link setup, authentication but no flow control or sequence numbering; X.25 is connection-oriented with SVCs.
- IP fragmentation across a smaller MTU (3x): Data per fragment = MTU - 20 header, rounded to multiple of 8 (820 -> 800). 1400 data + 20 = 1420 -> fragments of 800 and 600 data; offset in 8-byte units; MF=1 except last; TCP header only in first fragment.
- IP/TCP header field facts and order (3x): Fields: version, HLEN, service type, total length, identification, flags, fragment offset, TTL, protocol, checksum, addresses, options. TTL, checksum and fragment fields change in transit; addresses do not. Fragment offset is IP, not TCP.
- Ethernet/MAC address facts (3x): 48-bit address in hex; LSB of first byte 0 = unicast, 1 = multicast, all F = broadcast; MAC is globally unique.
- Classical ciphers (Caesar, transposition) and key exchange (3x): Caesar shifts each letter by k (decrypt = shift back k); transposition permutes positions; Diffie-Hellman exchanges secret keys.
- Firewall function and filtering criteria (3x): Firewall filters in/out traffic by source/destination IP, TCP/UDP ports; VPN simulates a private leased line.
- Nyquist and Shannon limits (3x): Nyquist bit rate = 2B log2(L); sampling rate >= 2 f_max; Shannon C = B log2(1 + SNR).
- Circuit vs packet switching statements (3x): Circuit switching reserves resources at setup, constant delay; packet switching shares links, variable delay, no dedicated path.
- UDP versus TCP services (3x): UDP is connectionless, offers no flow/congestion control or retransmission; TCP has both.
- DHCP step ordering (2x): Memorise DORA: Discover, Offer, Request, Ack (then client configures). Renewal: check lease timer, send DHCPREQUEST, server DHCPACK, update database.
- Propagation delay and bandwidth-delay product (2x): Propagation delay = length/speed; BDP = bandwidth x delay (use round-trip time when given RTT).
- CRC codeword formation (2x): Codeword = dataword followed by remainder (append, not add).
- CIDR block splitting and route aggregation (2x): Split a prefix by halves/quarters (add 1 bit or 2 bits); aggregate contiguous blocks by shortening the prefix.
- Ethernet delay calculation (10 Mbps, 2500 m, 512 B) (2x): Tt = frame bits / rate; Tp = distance/speed.
- CSMA/CD minimum frame size (2x): Min frame bits = bandwidth x 2Tp (round-trip); reverse to get speed/distance.
- RSA computation (2x): n = p*q; phi = (p-1)(q-1); e*d = 1 mod phi; C = M^e mod n.
- Period to frequency conversion (2x): f = 1/T; T = 100 ms gives 10 Hz = 10^-2 kHz.
- Throughput calculation (2x): Throughput = bits successfully delivered per second = (rate of requests x size in bits).
- TCP behaviour after server crash (2x): After reboot the server has no connection state; client data gets RST; client waiting without keepalive may hang.
- Congestion control mechanisms (2x): Choke packet notifies source; token bucket burst time = capacity/(output rate - fill rate).
- Wireless technology matching (CDMA, GSM, UMTS, WiFi) (2x): CDMA multiple access, GSM FDMA+TDMA hybrid, UMTS faster mobile data, WiFi wireless LAN.
- Cellular generations (2x): AMPS 1G analog; IS-95 2G CDMA/DSSS; 3G broadband CDMA.
- Sliding window mechanics (steps and Go-back-N variables) (2x): Sliding window: send window, ack, slide; in Go-back-N Sn stays at window end, only Sf moves on ack.
