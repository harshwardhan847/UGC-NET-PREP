FORMULAS AND FACTS
- Fuzzy complement: mu_A'(x)=1-mu_A(x) (Apply per element.)
- Fuzzy intersection / union: min(muA,muB) / max(muA,muB) (Standard Zadeh operators.)
- Algebraic sum / bounded sum / bounded difference: a+b-ab ; min(1,a+b) ; max(0,a-b) (Bounded sum uses min with 1.)
- Dual t-norm and s-norm: t(x,y)=1-s(1-x,1-y) (Substitute then simplify.)
- alpha-cut nesting: alpha1<alpha2 => A_alpha1 contains A_alpha2 (Higher cut gives smaller set.)
- Crossover point: mu_A(x)=0.5 (Core is mu=1, support is mu>0.)
- Number of models: 2^n assignments over n symbols; models of OR = 2^n - falsifying (B v C over 4 symbols gives 12; 4-literal clause gives 15.)
- Entailment: alpha |= beta iff M(alpha) subset of M(beta) (False |= anything.)
- Existential translation: exists x (P(x) AND Q(x)) (Never use implication with exists.)
- Minimax / alpha-beta: MAX takes max, MIN takes min; alpha=-inf, beta=+inf initially; best case O(b^(d/2)) (Alpha-beta gives same value as minimax.)
- A* evaluation: f(n)=g(n)+h(n); admissible: h<=h* (Consistent: h(n)<=c(n,n')+h(n').)
- Search complexities: BFS O(b^d); DFS O(bm); DLS O(bl); IDS O(bd) (Space complexity; RBFS is O(bd) space.)
- GA selection probability: p(x)=f(x)/sum f(x) (Convert binary chromosome first.)
- Schema order: order = number of fixed (non-*) positions (Wildcard positions do not count.)
- Certainty factors: AND: min; OR: max; CF(conclusion)=CF(premise)*CF(rule) (Example: min(0.5,0.8)=0.5 times 0.8 = 0.40.)
- Dempster-Shafer: Bel(A)+Bel(not A) <= 1 (Not equal 1 unlike probability.)
- Sigmoid: f(x)=1/(1+e^-x); f'=f(1-f); for 1/(1+e^-2x), f'(0)=2*0.25=0.5 (Scaling factor 2 doubles derivative.)
- Neuron weighted sum: y=k*sum w_i x_i (1*5+2*7+3*10+4*30=169, times 3 = 507.)
- Perceptron rule: w_new=w+eta*(t-y)*x (Single layer separates AND, OR, NOR but not XOR.)
- Gradient descent update: W(t+1)=W(t)-alpha*dE/dW (Minus sign.)
- Kohonen SOM update: w_new=(1-eta)*w_old+eta*x (Winner and neighbours.)
- K-means / Manhattan distance: centroid=mean of cluster points; d=|x1-x2|+|y1-y2| (Recompute centroid after assignment.)
- Decision tree to rules: AND along a branch, OR across branches (Disjunctive normal form.)
- Environment property: uncertain = not fully observable OR not deterministic; semi-dynamic: environment static but score changes (Common trap.)
- Hill-climbing shortcomings: local maxima, plateau, ridge (All three are listed.)

QUESTION FAMILIES (most repeated first; each is a question type the exam keeps reusing)
- Agent types, architecture and environments (7x): Simple reflex agent uses only current percept; utility-based handles happy/unhappy; learning agent improves performance; environment properties: observable, deterministic, static, semi-dynamic (environment fixed, performance score changes), uncertain = not fully observable OR not deterministic. MAS: multiple agents with diverse objectives and communication.
- A* optimality and heuristic admissibility (6x): A* optimal with admissible h (tree) / consistent h (graph); admissible = never overestimates; consistent = triangle inequality; A* expands all nodes with f<C* and none with f>C*; max of admissible heuristics dominates.
- GA odd-one-out: operators, encodings, selection (5x): Mutation: random resetting, scramble, inversion, swap, bit flip. Representations: binary, real, permutation (Gray also). Parent selection: roulette/fitness-proportional, tournament, rank, Boltzmann. 'Actual count' relates to selection.
- Backpropagation and weight update (5x): Backprop propagates error backward from output to input; gradient descent: W(t+1)=W(t)-alpha dE/dW. Training order: initialize weights, feed forward, loss, backprop, update.
- ANN passage questions (June 2024 re-exam) (5x): Read the passage: ANNs are inspired by the brain; input/hidden/output layers; weights adjusted to reduce error.
- Minimax root value of a game tree (4x): Evaluate bottom-up: MAX nodes take max of children, MIN nodes take min. Alpha-beta gives the same root value.
- Alpha-beta pruning true/false statements (4x): Facts: minimax is depth-first; alpha-beta returns the same value as minimax; pruning efficiency depends on move ordering; alpha init -inf, beta +inf; values updated along the search path; best case halves depth (O(b^(d/2))).
- Supervised vs unsupervised vs classification algorithm identification (4x): Supervised: regression, KNN, decision tree, logistic regression, SVM, backprop. Unsupervised: clustering, PCA, Apriori, SOM. Reinforcement: reward/punish with MDP. Regression is not classification.
- Clustering algorithm steps and k-means calculation (4x): K-means: choose k, init centroids, assign to nearest, update centroids as mean, repeat. DBSCAN: eps neighbours, core points via MinPts, expand density-connected points. Compute distance (Manhattan = sum |dx|+|dy|) to a recomputed centroid.
- Planning and STRIPS (4x): STRIPS is action-centric: each action has precondition and effect (add/delete lists); features are primitive or derived; no conditional effects directly. Planning graph gives heuristics; relaxation drops negative effects. Classic planning definition: init, actions, goal.
- ANN features and layer statements (4x): ANN: machine learning algorithm, handles large data, extracts features automatically, modelled on brain; training time grows with size; can be simulated on conventional computer; can include feedback. Information flows input, hidden, output.
- NN numerical computation (4x): Neuron output = f(sum w_i x_i + bias); linear transfer multiplies by constant; sigmoid 1/(1+e^-x), derivative f(1-f); perceptron update w += eta (t - y) x.
- Fuzzy set operations on membership values (3x): Complement=1-mu; intersection=min; union=max; algebraic sum=a+b-ab; bounded sum=min(1,a+b); bounded difference=max(0,a-b). Apply element-wise.
- Entailment definition and properties (3x): alpha entails beta (alpha |= beta) iff beta true in every model where alpha true; False entails everything; alpha |= (b and g) implies alpha |= b and alpha |= g; Horn KB works with forward/backward chaining.
- NLP components and NLU vs NLG (3x): NLU: morphological, syntactic, semantic, pragmatic analysis (no 'meaning analysis'). NLG: text planning, sentence planning, realization. Parsing: top-down, bottom-up, dependency, Earley; SMT is not a parser.
- Match search algorithms to evaluation function / space complexity (3x): Greedy: h(n); UCS/lowest-cost: g(n); A*: g+h. Space: BFS O(b^d), DFS O(bm), DLS O(bl), IDS O(bd).
- Dual pair of fuzzy t-norm and s-norm (2x): Use t(x,y)=1-s(1-x,1-y), so s(x,y)=1-t(1-x,1-y). Substitute 1-x,1-y into t, simplify 1 - (1-x)(1-y)/((1-x)+(1-y)-(1-x)(1-y)).
- Alpha-cut properties (2x): Alpha-cut = elements with mu>=alpha. Higher alpha gives smaller set (nested, decreasing). Union/intersection commute with cuts; complement does not except special cases.
- Count models of a propositional sentence (2x): Models over n symbols = 2^n assignments; count assignments making the sentence true. For an OR of literals, 2^n minus falsifying assignments.
- English to FOL: 'a country that borders both ...' (2x): Existential quantifier pairs with conjunction (AND), never implication.
- Knowledge-base design steps order (2x): Order: choose task domain, select atoms for propositions, axiomatize the domain, ask questions about the intended interpretation.
- GA fitness and selection probability calculation (2x): Fitness f(x); selection probability = f(x)/sum f; the parent chosen is the one with highest fitness. Convert binary string to decimal before f(x)=x^2.
- GA step sequence (2x): Order: initialization/evaluate fitness, selection of parents, crossover (prob pc), mutation (prob pm), repeat until termination.
- GA crossover types (2x): One-point: swap tails after one cut; two-point: swap middle segment; uniform: binary mask per gene decides which parent gives the gene.
- GA general concepts (2x): GA mimics evolution: selection, crossover/reproduction, mutation; stochastic hill-climbing with a population. Reproduction is the costliest step.
- Perceptron capability (2x): Single-layer perceptron solves linearly separable functions (AND, OR, NOR) but not XOR; single layer feed-forward network.
- Unsupervised neural nets / Kohonen SOM (2x): SOM is unsupervised, competitive learning; weight update w_new=(1-eta)w_old+eta x for winner and neighbours.
- Match search algorithms to properties (2x): Greedy best-first: incomplete even in finite spaces; A*: optimal if heuristic admissible; RBFS: O(bd) linear space; know the 4th option too.
- AND-OR search (2x): AND-OR search for nondeterministic environments; OR nodes are agent choices, AND nodes are environment outcomes; a solution is a subtree with a goal at each leaf (contingent plan).
