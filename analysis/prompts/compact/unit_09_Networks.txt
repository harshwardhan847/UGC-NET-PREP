FORMULAS AND FACTS
- Transmission delay: Tt = frame size (bits) / bandwidth (bps)
- Propagation delay: Tp = distance / propagation speed
- Bandwidth-delay product: BDP = bandwidth x delay (RTT if round trip given)
- Optimal sliding-window size: W = 1 + 2Tp/Tt
- Sliding-window efficiency / throughput: efficiency = W / (1 + 2Tp/Tt) capped at 1; throughput = efficiency x bandwidth
- Error detection/correction distance: Detect s errors: d_min = s + 1; correct t errors: d_min = 2t + 1
- Hamming distance: Number of bit positions where two words differ (weight of XOR)
- CRC codeword: Codeword = dataword || remainder (remainder from modulo-2 division after appending zeros)
- Bit stuffing flag: Frame flag 01111110 = 0x7E; stuff 0 after five consecutive 1s
- Nyquist bit rate: C = 2B log2(L)
- Shannon capacity: C = B log2(1 + SNR)
- Frequency and period: f = 1/T
- Fully connected links: n(n-1)/2
- CSMA/CD minimum frame: L_min = bandwidth x 2Tp
- Slotted ALOHA throughput: S = G e^(-G); pure ALOHA S = G e^(-2G)
- Token bucket burst duration: T = C / (M - rho) = capacity / (output rate - token rate)
- Token ring 1-bit delay: distance per bit = propagation speed / bit rate
- Hosts per subnet: 2^(host bits) - 2; subnets = 2^(subnet bits)
- Subnetting a block: new prefix = old prefix + log2(subnets); addresses = 2^(32 - prefix)
- IPv4 class ranges: A 0-127, B 128-191, C 192-223, D 224-239, E 240-255; A=50%, B=25%, C=12.5% of space
- IP fragmentation: data per fragment = floor((MTU - 20)/8)*8; offset = bytes/8
- IPv4 header decode: byte0 low nibble HLEN x 4; bytes 2-3 total length; byte 8 TTL; byte 9 protocol (6 TCP, 17 UDP, 1…
- RSA: n = pq; phi = (p-1)(q-1); ed = 1 mod phi; C = M^e mod n; M = C^d mod n
- Symmetric key count: N(N-1)/2 keys for N parties
- Cipher sizes: DES 64-bit block/56-bit key; 3DES 168; AES 128 block, 128/192/256 key; IDEA 64/128; Blowfish 32-448
- Line coding average bandwidth: NRZ-L N/2; MLT-3 N/3; 2B1Q N/4; 4D-PAM5 N/8; Manchester bit rate = half baud
- DHCP sequence: Discover, Offer, Request, Ack
- Hierarchical routing table size: entries = routers in own region + other regions in cluster + other clusters
- Piconet: 1 master + up to 7 active slaves
