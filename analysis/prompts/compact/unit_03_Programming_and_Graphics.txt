FORMULAS AND FACTS
- Frame buffer size: bytes = X * Y * bits_per_pixel / 8 (640*480*12/8 = 460800 B = 450 KB)
- Colour lookup table size: LUT = 2^bits_per_pixel entries * (3*8 bits) = 2^bits * 3 bytes
- Refresh rate: rate = 1 / (pixels * access time) (640*480*200 ns = 61.4 ms, about 16 fps)
- Aspect-ratio resize: h2 = h1 * w2 / w1 (768*640/1024 = 480)
- 2D scaling: x' = sx*x, y' = sy*y; matrix diag(sx, sy)
- Scaling about fixed point F: P' = F + s(P - F)
- Homogeneous 2D matrices: Translate [[1,0,tx],[0,1,ty],[0,0,1]]; Scale diag(sx,sy,1); Shear-x [[1,h,0],[0,1,0],[0,0,1]…
- Reflection about X axis: diag(1,-1); determinant -1, so not a rotation
- Perspective division: x' = x/z, y' = y/z via homogeneous w; non-linear in Cartesian, linear only in homogeneous coord…
- Orthographic projection: Affine: preserves parallel lines, no size change with depth
- Cubic Bezier: P(t)=sum B_i P_i, with P(0)=P0, P(1)=P3, P(1/2)=(P0+3P1+3P2+P3)/8; 4 control points, inside convex hull
- Phong specular term: I_s = k_s (R . V)^n (reflected vector and view vector)
- Clipping facts: Cohen-Sutherland: accept if both outcodes 0000, reject if AND != 0; Sutherland-Hodgman clips polygons…
- Row-major 3D address: addr(A[r][s][t]) = base + w*(b*c*r + c*s + t) for int A[a][b][c]
- Array/pointer identity: a[i] = *(a+i); a[i][j][k] = *(*(*(a+i)+j)+k); ptr[-1] legal; &arr+1 moves past whole array
