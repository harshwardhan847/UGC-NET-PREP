FORMULAS AND FACTS
- Cyclomatic complexity: V(G) = E - N + 2 = P + 1 = number of regions
- Risk exposure: RE = P x L
- Cost performance index: CPI = BCWP / ACWP
- Availability: A = MTBF / (MTBF + MTTR)
- Exponential reliability: R(t) = e^(-t/MTTF), MTTF = mean of times between failures
- Web app integrity: integrity = 1 - threat x (1 - security)
- Software maturity index: SMI = (Mt - (Fa + Fc + Fd)) / Mt
- Effort from productivity: Effort = size / productivity; size = effort x rate
- Project duration: days = effort(person-hours) / (team size x hours per day)
- Cost from effort: cost = effort (PM) x monthly salary x team; or FP x productivity
- Basic COCOMO organic: E = 2.4 (KLOC)^1.05 PM; D = 2.5 E^0.38
- Software (Putnam) equation: E = [LOC x B^0.333 / P]^3 x (1/t^4)
- Boundary value analysis count: 4n + 1 test cases for n variables (robust: 6n + 1)
- Defect removal efficiency: DRE = E / (E + D)
- Cohesion ranking (best to worst): functional > sequential > communicational > procedural > temporal > logical > coincidental
- Coupling ranking (low to high): data < stamp < control < external < common < content
- CMM levels: Initial, Repeatable, Defined, Managed, Optimizing
- Maintenance types: corrective (bugs), adaptive (environment), perfective (features/restructure), preventive
- FDD order: overall model, feature list, plan by feature, design by feature, build by feature
- Generic framework activities: Communication, Planning, Modeling, Construction, Deployment
- Testing sequence: Unit, Integration, System, Acceptance
- Coverage hierarchy: path coverage implies branch implies statement coverage
- ISO 9126 characteristics: functionality, reliability, usability, efficiency, maintainability, portability
