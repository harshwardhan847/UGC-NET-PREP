FORMULAS AND FACTS
- Chomsky hierarchy: Regular ⊂ DCFL ⊂ CFL ⊂ CSL ⊂ Recursive ⊂ RE; Type3=FA, Type2=PDA, Type1=LBA, Type0=TM
- CFL closure: Closed: ∪, ·, *, reversal, homomorphism, ∩ regular. Not closed: ∩, complement, difference
- Regular closure: Closed under all of union, concat, star, complement, intersection, reversal, homomorphism, quotient
- Class closure: REC closed under complement; RE not closed under complement; regular* ∩ CFL is CFL
- CNF form: A → BC or A → a; derivation of length-n string takes 2n-1 steps
- CNF conversion bound: (K-1)|P| + |T|
- GNF: A → a α (terminal first then variables)
- Ambiguity: Ambiguous iff some string has ≥2 parse trees ⇔ ≥2 leftmost derivations ⇔ ≥2 rightmost
- Pumping lemma (regular): w=xyz, |xy|≤p, |y|≥1, xy^i z ∈ L for all i≥0
- Pumping lemma (CFL): w=uvwxy, |vwx|≤p, |vx|≥1, uv^i wx^i y ∈ L
- Regex identities: φ+L=L; εL=L; φL=φ; (a*+b)*=(a+b)*; precedence star > concat > union
- Arden theorem: R = Q + RP ⇒ R = QP*
- Moore/Mealy: Every Moore machine has an equivalent Mealy machine and vice versa
- PDA power: PDA = CFL; two stacks = TM; DPDA+prefix property ↔ LR(0)
- Decidability table: Regular: all decidable. CFL: membership, emptiness, finiteness decidable; equivalence, universality undecidable. CSL:…
- Rice theorem: Every non-trivial semantic property of L(M) is undecidable
- PCP: Undecidable in general; solve instances by matching strings
- TM definitions: δ: Q×Γ→Q×Γ×{L,R}; multi-tape δ: Q×Γ^k→Q×Γ^k×{L,R,S}^k; recursive language = TM halts on all inputs
- Parser power: LR(0) < SLR < LALR(1) < CLR(1); LL(1) ⊂ LR(1); Yacc = LALR
- Bottom-up parsing: Reverse of rightmost derivation; scans left to right; stack+buffer+table
- FOLLOW: FOLLOW(X) ⊇ FIRST(β) for A→αXβ; if β nullable add FOLLOW(A)
- LR item: A → ε yields item A → ·
- Quadruple count: One quadruple per operator
- Basic block leaders: First instruction; target of any jump; instruction immediately after a jump
- Compiler phases order: Lexical → syntax → semantic → intermediate code → optimisation → code generation
- Constant folding: Compile-time evaluation of constant expressions
- L* membership: Parse into {ab,aa,baa} blocks greedily
