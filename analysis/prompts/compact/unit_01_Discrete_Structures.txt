FORMULAS AND FACTS
- Conditional equivalences: p->q = ~p v q = ~q->~p; ~(p->q) = p ^ ~q
- Biconditional: p<->q = (p->q)^(q->p) = (p^q) v (~p^~q); ~(p<->q) = ~p<->q
- De Morgan / quantifier negation: ~(p^q)=~p v ~q; ~exists x P = forall x ~P; ~forall x P = exists x ~P
- Implication distribution: (p->r)^(q->r) = (p v q)->r ; (p^q)->r = (p->r) v (q->r)
- Quantifier non-equivalences: forall x(P v Q) != forall x P v forall x Q ; exists x(P^Q) != exists x P ^ exists x Q
- Reflexive relations count: 2^(n^2-n) on n elements (4 elements: 2^12)
- Inclusion-exclusion: |AuBuC| = |A|+|B|+|C|-|AnB|-|AnC|-|BnC|+|AnBnC|
- Pigeonhole: min objects to guarantee r in one box with k boxes: k(r-1)+1
- Stars and bars: non-negative solutions of x1+..+xk=n : C(n+k-1,k-1)
- Onto functions: onto(n->k) = sum_i (-1)^i C(k,i)(k-i)^n
- Multinomial coefficient: coefficient of x^a y^b z^c in (x+y+z)^n = n!/(a!b!c!)
- Linear recurrence solution: repeated root r: a_n=(A+Bn)r^n; f(n)=a f(n/2)+c solved with n=2^K
- Catalan numbers: binary trees / BSTs with n nodes = (2n)!/((n+1)!n!)
- Handshake lemma: sum of degrees = 2|E|; number of odd-degree vertices is even
- Tree and forest edges: tree: E=V-1; forest with k components: E=V-k
- Euler's planar formula: V-E+F=2 (connected planar); E<=3V-6
- Cayley spanning trees: tau(K_n)=n^(n-2); tau(C_n)=n
- Hamiltonian conditions: Dirac: deg(v)>=n/2; Ore: deg(u)+deg(v)>=n for non-adjacent u,v; K(m,n) Hamiltonian iff m=n>=2
- Colouring facts: bipartite iff 2-colourable iff no odd cycle; planar => 4-colourable; chi<=Delta+1
- Edge counts of graph families: K_n: n(n-1)/2; C_n: n; W_n (n vertices): 2(n-1); K_{n,n}: n^2; Q_n: n*2^(n-1)
- Boolean algebra counts: Boolean functions of n variables: 2^(2^n); finite Boolean algebra has 2^n elements
- Poset under divisibility: GLB = gcd, LUB = lcm
- Dual of Boolean expression: swap + and ., swap 0 and 1; absorption a+ab=a
- Poisson: P(X=0)=e^(-lambda t); P(X=k)=e^(-lt)(lt)^k/k!
- Conditional and union probability: P(A|B)=P(AnB)/P(B); P(AuB)=P(A)+P(B)-P(AnB); independent: 1-(1-a)(1-b)
- Total 5-card hands: C(52,5)=2,598,960
- Euler phi and theorems: phi(n)=n prod(1-1/p); a^phi(n)=1 mod n (gcd=1); a^(p-1)=1 mod p; phi(45)=24
