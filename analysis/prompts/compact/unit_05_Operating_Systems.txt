FORMULAS AND FACTS
- Deadlock-free process bound: R >= n(m-1)+1, so n_max = floor((R-1)/(m-1))
- Banker: Need: Need = Max - Allocation; safe if some order lets every process finish with Available
- Disk capacity: surfaces x tracks per surface x sectors per track x bytes per sector
- Sector-address bits: log2(surfaces x tracks x sectors)
- Rotational delay: max = 60/rpm seconds; average = half of that
- Data transfer rate: bytes per track x revolutions per second
- Seek time: total head movement x time per cylinder
- Disk policies: SCAN goes to end then reverses; C-SCAN goes to end then jumps to start; LOOK/C-LOOK turn at the last r…
- Inode maximum file size: (direct + p + p^2) x block size, p = block size/address size
- Tape write time: (data / recording density) / speed (+ inter-block gaps)
- Paging sizes: pages = VA/page size; offset bits = log2(page); frames = PM/page; page table size = pages x entry size
- Internal fragmentation: unused space in last page = pages x page size - process size
- EMAT with TLB: h(t+m) + (1-h)(t+2m)
- EAT with page faults: (1-p)m + p x fault time; or p + q/100 if one fault per 100
- Swap time: 2 x (size/transfer rate) + latencies
- Belady's anomaly: Occurs for FIFO; LRU and optimal are stack algorithms and have no anomaly
- Little's law: n = lambda x W
- Scheduling times: TAT = CT - AT; WT = TAT - BT; RT = first run - AT; HRRN ratio = (W+S)/S
- RR worst-case wait: (n-1) x q
- Counting semaphore: final = initial - #P + #V
- fork count: k sequential forks create 2^k processes
- RAID levels: 0 striping,1 mirror,2 bit ECC,3 bit parity,4 block parity,5 distributed block parity,6 P+Q
- Linux interrupt priority: user < kernel system service < bottom half < top half
- Thread sharing: Shared: code,data,files,address space. Private: stack,registers,PC
- Thread model concurrency: one-to-one > many-to-many > many-to-one
- Boot order: ROM firmware -> boot block -> bootstrap loader -> kernel
- Layered file system: Application -> logical FS -> file organization module -> basic FS -> I/O control
- File allocation: Contiguous has external fragmentation; linked and indexed do not
- Compiler phase order: lexical, syntax, semantic, intermediate code, optimization, code generation
- Unix facts: fork creates child; exec loads program; kill signals; clone selective sharing; wc -l; lpr; /etc/passwd; c…
