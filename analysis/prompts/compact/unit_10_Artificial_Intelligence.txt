FORMULAS AND FACTS
- Fuzzy complement: mu_A'(x)=1-mu_A(x)
- Fuzzy intersection / union: min(muA,muB) / max(muA,muB)
- Algebraic sum / bounded sum / bounded difference: a+b-ab ; min(1,a+b) ; max(0,a-b)
- Dual t-norm and s-norm: t(x,y)=1-s(1-x,1-y)
- alpha-cut nesting: alpha1<alpha2 => A_alpha1 contains A_alpha2
- Crossover point: mu_A(x)=0.5
- Number of models: 2^n assignments over n symbols; models of OR = 2^n - falsifying
- Entailment: alpha |= beta iff M(alpha) subset of M(beta)
- Existential translation: exists x (P(x) AND Q(x))
- Minimax / alpha-beta: MAX takes max, MIN takes min; alpha=-inf, beta=+inf initially; best case O(b^(d/2))
- A* evaluation: f(n)=g(n)+h(n); admissible: h<=h*
- Search complexities: BFS O(b^d); DFS O(bm); DLS O(bl); IDS O(bd)
- GA selection probability: p(x)=f(x)/sum f(x)
- Schema order: order = number of fixed (non-*) positions
- Certainty factors: AND: min; OR: max; CF(conclusion)=CF(premise)*CF(rule)
- Dempster-Shafer: Bel(A)+Bel(not A) <= 1
- Sigmoid: f(x)=1/(1+e^-x); f'=f(1-f); for 1/(1+e^-2x), f'(0)=2*0.25=0.5
- Neuron weighted sum: y=k*sum w_i x_i
- Perceptron rule: w_new=w+eta*(t-y)*x
- Gradient descent update: W(t+1)=W(t)-alpha*dE/dW
- Kohonen SOM update: w_new=(1-eta)*w_old+eta*x
- K-means / Manhattan distance: centroid=mean of cluster points; d=|x1-x2|+|y1-y2|
- Decision tree to rules: AND along a branch, OR across branches
- Environment property: uncertain = not fully observable OR not deterministic; semi-dynamic: environment static but score changes
- Hill-climbing shortcomings: local maxima, plateau, ridge
