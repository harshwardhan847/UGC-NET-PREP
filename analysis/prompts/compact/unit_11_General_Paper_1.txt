FORMULAS AND FACTS
- Percent change: (New - Old)/Old x 100
- A is x% more than B: (A - B)/B x 100
- Average: Sum of values / number of values
- Share from ratio: Share = ratio part/sum of parts x total; fractions first multiplied by LCM (1/2:1/3:3/4 = 6:4:9)
- Work rates: Sum of 1/time = 1/total time
- Man-hours: M1 D1 H1 / W1 = M2 D2 H2 / W2
- Speed-time-distance: Time = distance/speed; sum of segment times = total time
- Discount: SP = MP x (100 - d)/100
- Mixture cost and gain: SP = (total cost/total quantity) x (100 + gain%)/100
- Direction distance: Net displacement = sqrt(dx^2 + dy^2)
- Base conversion: (abc)_n = a n^2 + b n + c
- Mirror coding: A=Z, B=Y ...: letter + mirror letter = 27
- Alternating shift coding: +2, -2, +2 ... on successive letters
- Number series: Differences, ratios, second differences
- Square of opposition: A-O and E-I contradictory; A-E contrary (both false allowed); I-O subcontrary
- Denotation vs connotation: Greater connotation implies lesser denotation
- Syllogism AII-2: Middle term predicate in both premises gives undistributed middle fallacy
- OSI layers: Physical, Data link, Network, Transport, Session, Presentation, Application
- Memory taxonomy: LTM = explicit (episodic, semantic) + implicit (procedural, priming)
- Bandura observational learning: Attention, retention, reproduction (production), motivation
- Mercalli vs Richter: Mercalli = intensity/damage; Richter = magnitude/energy
- Education timeline: Wood 1854, Curzon 1904, Sadler 1917, UEC 1948, SEC 1952, UGC 1956, Kothari 1964
